# 石化厂盲板与工艺隔离完整性管理信息系统

## 产品需求文档（PRD）

**版本：** 2.0  
**状态：** 修订稿  
**日期：** 2026-07-27  
**修订说明：** 本版在 v1.0 基础上去除盲板库存与检验管理相关内容，进一步去除盲板实物管理（盲板信息下沉至作业记录），新增隔离点位管理、隔离点位及盲板组态管理、工艺处置方案管理，并将功能需求拆分为 PC 端与移动端，标注两端交互点。

## 1. 项目背景

### 1.1 行业现状与痛点

在石化行业生产运维过程中，盲板抽堵作业是工艺隔离的核心手段，直接关系到装置检修、动火作业、受限空间作业等高风险活动的安全。当前绝大多数石化厂的盲板管理仍停留在以下水平：

- **纸质台账管理**：盲板及隔离点位信息登记在纸质表格或Excel中，更新滞后、易丢失、难追溯。
- **信息传递断层**：隔离方案编制、现场执行、状态确认各环节信息不互通，方案与执行"两张皮"。
- **位置依赖人工记忆**：盲板安装位置依赖现场人员经验判断，缺乏数字化校验手段，"最后一米"防错能力薄弱。
- **状态缺乏实时监控**：盲板通/盲状态变更后无法及时同步，管理人员无法实时掌握全厂隔离态势。
- **隔离点位缺乏统一治理**：隔离点位散落于各装置图纸与台账中，没有统一的主数据与生命周期管理，点位新增、变更、停用无流程受控，点位与设备/管线的对应关系不清晰。
- **监控画面缺乏组态化能力**：隔离状态展示依赖静态截图或手工标注，无法将隔离点位、盲板状态与工艺流程图实时绑定，难以做到"所见即所控"。
- **作业流程不统一**：不同风险等级的隔离作业采用相同的管理流程，低风险过度管控、高风险管控不足并存。
- **合规审计压力大**：GB 30871-2022对盲板抽堵作业提出明确要求，纸质台账难以满足合规审计的追溯性要求。

### 1.2 从"盲板管理"到"工艺隔离完整性管理"

本项目不局限于传统的盲板台账管理，而是以**工艺隔离完整性**为核心理念，构建覆盖"方案—执行—监控—闭环"全链条的信息化管理体系。核心理念围绕三个闭环：

| 闭环维度         | 内涵                               | 管理目标             |
| ------------ | -------------------------------- | ---------------- |
| **隔离边界正确性**  | 隔离方案中确定的隔离点是否准确、完整，是否覆盖了所有能量隔离需求 | 方案编制正确、审批严谨、变更受控 |
| **隔离方式可靠性**  | 盲板安装质量、型号匹配、位置准确、挂牌规范            | 最后一米防错、安装质量可追溯   |
| **隔离状态持续受控** | 盲板通/盲状态在作业全生命周期中保持可知、可控、可追溯      | 状态实时更新、异常告警、停工联动 |

### 1.3 合规依据

本系统设计严格遵循以下法规和标准：

- **GB 30871-2022**《危险化学品企业特殊作业安全规范》——对盲板抽堵作业的作业审批、安全措施、作业要求等作出明确规定
- **GB/T 45001-2020**《职业健康安全管理体系》
- 企业内部的工艺隔离管理标准与操作规程

## 2. 建设目标

### 2.1 总体目标

构建石化厂工艺隔离完整性管理信息平台，以**隔离点位**为管理基座、以**工艺处置方案**为安全前置条件、以**盲板作业**为执行核心、以**组态可视化**为监控手段，实现隔离点位全生命周期受控、工艺处置规范执行、盲板作业全过程可追溯、隔离状态全厂级实时可知、可管控、可预警。

### 2.2 具体目标

| 编号     | 目标                   | 说明                                                              |
| ------ | -------------------- | --------------------------------------------------------------- |
| **G1** | **隔离点位全生命周期受控**      | 隔离点位从新增、变更、停用到启用的全过程纳入流程化管理，点位主数据准确、唯一、可追溯                      |
| **G2** | **盲板作业全程可追溯**        | 每一块盲板的每一次安装、拆除、位置变更均有完整记录，形成可追溯的作业档案                            |
| **G3** | **施工位置准确无误（最后一米防错）** | 通过"五码一致"校验机制，确保方案指定位置、现场扫码位置、实际安装位置一致，杜绝错装漏装                    |
| **G4** | **作业流程差异化、标准化**      | 根据风险等级（A/B/C/D）匹配不同的作业流程，高风险高管控、低风险简化流程                         |
| **G5** | **通盲状态精准管理**         | 实时记录每一块盲板的通/盲状态及变更历史，支持全厂级状态监控看板                                |
| **G6** | **组态化可视化监控与智能预警**    | 通过组态画面将隔离点位、盲板状态与工艺流程图实时绑定，以流程图、三维模型、列表等多种方式呈现全厂隔离状态，异常情况自动预警推送 |
| **G7** | **隔离完整性闭环管理**        | 从方案编制→审批→执行→确认→恢复→归档，形成完整的PDCA闭环                                |

## 3. 设计原则

### 3.1 合规底线原则

- 系统设计以GB 30871-2022为最低合规要求，所有功能不得低于国标。
- 审批流程、作业票管理、安全措施确认等环节严格遵循法规要求。
- 系统日志和操作记录满足合规审计追溯要求。

### 3.2 风险差异化原则

- 对不同风险等级的隔离作业实施差异化管理流程，不搞"一刀切"。
- 风险等级自动判定为主、手动微调为辅，确保分级准确。
- 高等级风险强化管控措施，低等级风险简化流程提升效率。

### 3.3 系统自动化原则

- 尽可能通过系统自动完成规则判定、状态计算、预警推送等工作。
- 减少人工录入和手动判断环节，降低人为失误风险。
- 数据一次录入、多处复用，避免信息孤岛。

### 3.4 一线简洁原则

- 现场作业人员的操作界面以移动端为主，流程简洁、指引清晰。
- 扫码为主、手动输入为辅，降低现场操作门槛。
- 关键操作步骤提供明确的指引和确认提示，防止误操作。

### 3.5 组态化原则

- 隔离点位与盲板的监控展示以组态画面为载体，图元与数据实时绑定，所见即所控。
- 组态画面一次配置、多端复用（PC端监控、移动端查看）。
- 组态编辑与业务数据解耦，画面调整不影响底层主数据。

## 4. 风险分级管理

### 4.1 ABCD四级风险分类

| 风险等级   | 等级标识    | 适用场景                          | 管控要求                               |
| ------ | ------- | ----------------------------- | ---------------------------------- |
| **A级** | 🔴 高风险  | 涉及重大危险源、关键装置、有毒有害/易燃易爆介质、系统隔离 | 最高级别管控，8步完整流程，隔离总负责人全程参与，多级审批，旁站监护 |
| **B级** | 🟠 中高风险 | 涉及一般危险化学品、重要管线隔离、跨装置作业        | 5步标准流程，隔离总负责人审批，专职监护人              |
| **C级** | 🟡 中风险  | 常规管线隔离、低毒介质、非关键区域             | 4步简化流程，工艺工程师审批，作业负责人监护             |
| **D级** | 🟢 低风险  | 无毒无害介质、常温水系统、非危险区域            | 2步简易流程，作业负责人确认即可                   |

### 4.2 风险等级自动判定规则

系统根据以下条件自动判定风险等级，以满足**任一条件**即判定为该等级：

#### A级判定条件（满足任一即判定为A级）

1. 隔离介质属于**极度危害/高度危害**（GBZ 230-2010 职业性接触毒物危害程度分级中的Ⅰ级、Ⅱ级）
2. 隔离介质为**易燃易爆**且操作压力≥1.0MPa或温度≥闪点
3. 隔离点位于**重大危险源**单元内
4. 涉及**关键装置**或**核心机组**的工艺隔离
5. 隔离方案涉及**系统隔离**（即需要关闭整个系统或单元）
6. 单次作业涉及盲板数量≥**10块**

#### B级判定条件（满足任一即判定为B级）

1. 隔离介质属于**中度危害**（Ⅲ级）或易燃易爆但压力/温度低于A级阈值
2. 隔离点位于**危险化学品**存储或使用区域
3. 涉及**跨装置**管线隔离
4. 单次作业涉及盲板数量**5~9块**

#### C级判定条件（满足任一即判定为C级）

1. 隔离介质属于**轻度危害**（Ⅳ级）或一般化学品
2. 常规管线隔离，不涉及关键装置
3. 单次作业涉及盲板数量**2~4块**

#### D级（默认）

- 无毒无害介质（水、蒸汽、空气、氮气等），且非危险区域
- 单次作业涉及盲板数量**1块**
- 不满足以上所有条件的，默认为D级

#### 手动微调机制

- 系统自动判定等级后，允许**隔离总负责人**在审批环节进行手动调整（升/降一级）。
- 上调等级不限条件，下调等级需填写原因说明并经过安全管理人员确认。
- 所有等级调整记录归入审计日志。

### 4.3 差异化作业流程设计

#### A级（8步流程）

```
步骤1: 隔离方案编制 → 步骤2: 隔离方案审批（多级）→ 步骤3: 作业申请 → 
步骤4: 作业审批（含安全措施确认）→ 步骤5: 现场交底（JSA/JHA）→ 
步骤6: 现场执行（扫码-安装-确认-Hold Point检查）→ 
步骤7: 隔离恢复/拆除 → 步骤8: 归档验收
```

**关键特征：**

- 隔离方案须经工艺工程师、安全管理人员、隔离总负责人三级审批
- 现场执行设8个强制Hold Point检查点
- 需要旁站监护
- 完工后须进行隔离完整性验收

#### B级（5步流程）

```
步骤1: 隔离方案编制 → 步骤2: 作业申请与审批 → 
步骤3: 现场交底 → 步骤4: 现场执行 → 步骤5: 隔离恢复
```

**关键特征：**

- 隔离方案须经工艺工程师审批
- 现场执行设5个Hold Point检查点
- 专职监护人

#### C级（4步流程）

```
步骤1: 隔离方案编制 → 步骤2: 作业申请与审批 → 
步骤3: 现场执行 → 步骤4: 隔离恢复
```

**关键特征：**

- 方案审批由工艺工程师负责
- 现场执行设4个Hold Point检查点
- 作业负责人兼任监护人

#### D级（2步流程）

```
步骤1: 作业申请 → 步骤2: 现场执行
```

**关键特征：**

- 无需编制隔离方案，直接填写作业申请
- 作业负责人确认即可
- 现场执行设2个Hold Point检查点

## 6. 核心概念与数据模型

### 6.1 隔离点主数据

隔离点是工艺隔离方案中确定的、需要安装盲板的具体管线位置，是整个系统的管理基座。

| 字段         | 类型  | 说明                     |
| ---------- | --- | ---------------------- |
| 隔离点ID      | 字符串 | 唯一标识，编码规则：装置代码+区域代码+序号 |
| 隔离点编码      | 字符串 | 现场二维码/RFID对应的点位编码      |
| 装置/单元      | 外键  | 所属装置或工艺单元              |
| 管线号        | 字符串 | 对应PID图中的管线编号           |
| 公称直径DN     | 整型  | 管线公称直径（mm）             |
| 公称压力PN     | 浮点  | 管线公称压力（MPa）            |
| 介质名称       | 字符串 | 管内介质名称                 |
| 介质状态       | 枚举  | 气态/液态/气液混合             |
| 介质危害等级     | 枚举  | 极度/高度/中度/轻度/无毒         |
| 操作温度       | 浮点  | 正常操作温度（℃）              |
| 操作压力       | 浮点  | 正常操作压力（MPa）            |
| 法兰类型       | 字符串 | 法兰标准与类型                |
| 法兰规格       | 字符串 | 法兰尺寸规格                 |
| 坐标位置       | 坐标  | 在三维模型中的坐标（X/Y/Z）       |
| 所属区域       | 字符串 | 按装置划分的区域编码             |
| 点位分类       | 枚举  | 物理盲板点/阀门隔离点/双阀隔离点/其他   |
| 是否属于重大危险源  | 布尔  | 标识是否在重大危险源单元内          |
| 是否关键装置     | 布尔  | 标识是否属于关键装置             |
| 关联设备位号     | 外键  | 绑定的设备/管线位号             |
| 适配盲板规格     | 字符串 | 该点位适配的盲板型号与规格要求        |
| 当前安装盲板二维码 | 字符串 | 当前安装的盲板实物二维码（如为盲状态）  |
| 当前通盲状态     | 枚举  | 通/盲/盲板已拆除/未知           |
| 点位生命周期状态   | 枚举  | 草稿/在用/停用/变更中/作废        |
| 状态更新时间     | 时间戳 | 最后一次状态变更时间             |
| 组态图元ID     | 外键  | 关联的组态画面图元ID（用于可视化绑定）   |
| 附件         | 文件  | PID图截图、现场照片等           |

### 6.2 隔离点生命周期记录

记录隔离点从创建到作废的全过程变更轨迹。

| 字段     | 类型  | 说明                    |
| ------ | --- | --------------------- |
| 记录ID   | 整型  | 自增主键                  |
| 隔离点ID  | 外键  | 关联的隔离点                |
| 变更类型   | 枚举  | 新增/信息变更/位置变更/停用/启用/作废 |

| 变更后内容  | 文本  | 变更后的关键字段快照            |
| 变更原因   | 文本  | 变更原因说明                |
| 发起人    | 字符串 | 变更发起人                 |
| 审批人    | 字符串 | 变更审批人                 |
| 变更时间   | 时间戳 | 变更生效时间                |

### 6.3 盲板安装状态

盲板在每次安装/拆除操作中产生的状态记录。盲板的身份与规格信息在扫码安装时从盲板实物二维码中读取并快照记录，无需维护盲板实物。

| 字段     | 类型  | 说明                         |
| ------ | --- | -------------------------- |
| 记录ID   | 整型  | 自增主键                       |
| 盲板二维码  | 字符串 | 安装时扫描的盲板实物二维码/RFID编码        |
| 盲板型号   | 枚举  | 8字盲板/插板/垫环/盲法兰/其他（扫码读取快照）  |
| 公称直径DN | 整型  | 盲板公称直径mm（扫码读取快照）           |
| 公称压力PN | 浮点  | 盲板压力等级MPa（扫码读取快照）          |
| 盲板材质   | 字符串 | 碳钢/不锈钢/合金钢/其他（扫码读取快照）      |
| 隔离点ID  | 外键  | 安装位置ID                     |

## 7. 功能需求

> 本章将功能需求按使用终端划分为 **7.1 PC 端功能需求** 与 **7.2 移动端功能需求** 两大部分。两端存在联动的需求以 **【PC↔移动端交互】** 标注，并在 **7.3 PC 端与移动端交互总览** 中集中说明。

### 7.1 PC 端功能需求

PC 端面向管理人员、工程师、组态管理员与系统管理员，承担主数据维护、方案编制与审批、组态配置、监控看板、报表统计与系统管理等工作。

####

#### 7.1.1 隔离点管理

隔离点作为装置层级下的位置属性进行管理，关注其基本台账与最终状态，不管理生命周期过程。

- **装置层级结构**：工厂→装置→单元→隔离点的树形层级结构，支持增删改查。
- **隔离点台账**：维护隔离点基本档案（编码、名称、所属装置/单元、介质、压力/温度等级、危害等级、点位类型、适配盲板规格、关联设备位号/管线号），支持手工录入与批量导入（Excel），自动生成二维码。
- **隔离点状态**：展示并维护隔离点当前通/盲状态与占用/锁定状态，状态由现场作业驱动更新。**【PC↔移动端交互】** 移动端现场安装/拆除操作实时回传，PC 端状态同步刷新。
- **状态台账总览**：全厂隔离点状态一览，按装置、介质类型、危害等级、占用状态等筛选，异常状态（长期挂盲未拆、状态冲突等）自动高亮标识，支持状态变更历史追溯。
- **位置标注**：支持在三维模型或流程图上标注隔离点位置（坐标绑定），信息变更时保留变更历史。
- **二维码管理**：批量生成/打印/补打隔离点二维码，扫描可快速跳转至隔离点详情页。**【PC↔移动端交互】** 移动端现场扫码后拉取档案，PC 端同步扫码日志。

#### 7.1.2 隔离方案管理

##### 7.1.2.1 方案编制

- **方案模板**：提供标准化的隔离方案编制模板，引导用户完整填写。
- **隔离点选择**：支持从隔离点台账中选择隔离点，系统自动关联介质、压力、温度等工艺参数。
- **盲板建议**：根据隔离点规格要求（口径、压力等级、材质）自动匹配符合条件的盲板，按库存可用状态排序推荐。
- **方案版本管理**：方案修改走版本控制，历史版本可追溯。
- **方案关联图纸**：支持上传PID图、隔离边界图等附件，并在图上标注隔离点位置。

##### 7.1.2.2 方案审批与版本

- **差异化审批流程**：根据风险等级自动匹配审批流程（A级三级审批、B级二级审批等）。
- **审批意见留痕**：所有审批意见、修改记录、驳回原因均永久保存。
- **方案版本冻结**：审批通过后方案自动冻结，变更需发起新版本。
- **移动端审批支持**：审批节点支持在移动端完成（详见 7.2.7）。**【PC↔移动端交互】** 方案在 PC 端编制提交后，审批通知推送至移动端；移动端审批结果实时回写 PC 端方案状态。

##### 7.1.2.3 方案与作业关联

- 一个隔离方案可关联多次作业（如方案中的多块盲板可分多次施工）。
- 作业执行时自动关联方案中的隔离点信息和安全要求。
- 方案变更时，未完成的关联作业自动触发预警。

#### 7.1.3 工艺处置方案管理

工艺处置方案是隔离作业的前置必要条件。在编制隔离方案之前，工艺工程师需先编制工艺处置方案，明确管线/设备的排空、置换、吹扫、清洗等处置步骤及验收标准。处置方案执行完毕并确认合格后，方可进入盲板安装作业。

##### 7.1.3.1 处置方案编制

- **方案模板**：提供标准化的工艺处置方案编制模板，按处置类型（排空/置换/吹扫/清洗/蒸煮/钝化）提供预设步骤模板。
- **关联隔离方案**：处置方案与隔离方案一一绑定，编制处置方案时自动带入隔离方案涉及的管线号、设备位号、介质信息。
- **处置步骤编排**：支持添加、删除、排序处置步骤，每步设定处置类型、处置对象、处置方法、预计时长、前置条件、验收标准及安全注意事项。
- **处置目标设定**：设定处置后应达到的安全条件（如：可燃气体浓度<0.5%LEL、氧含量19.5%~23.5%、有毒气体浓度低于接触限值等）。
- **方案关联附件**：支持上传P\&ID图、安全分析报告等附件。

##### 7.1.3.2 处置方案审批

- **审批流程**：处置方案须经工艺工程师编制、安全管理人员审核，高风险（A/B级）隔离方案关联的处置方案需隔离总负责人终审。
- **审批意见留痕**：所有审批意见、修改记录、驳回原因均永久保存。
- **方案冻结**：审批通过后方案自动冻结，变更需发起新版本。

##### 7.1.3.3 处置方案执行监控

- **执行进度监控**：PC 端实时展示处置方案各步骤的执行状态（待执行/执行中/已完成/已跳过）。**【PC↔移动端交互】** 移动端现场执行确认结果实时回传 PC 端，更新步骤状态。
- **异常处置**：处置步骤确认不合格时，自动标记为异常，需填写异常说明与处理措施，经审核后方可重新执行或跳过。
- **处置完成确认**：所有处置步骤确认合格后，处置方案状态自动变更为"已完成"，隔离方案方可进入作业申请环节。**【PC↔移动端交互】** 处置完成通知推送至移动端，现场人员可继续后续盲板作业。

##### 7.1.3.4 处置方案与隔离方案联动

- 隔离方案编制时，系统强制校验关联的处置方案是否已审批通过；未通过则禁止提交隔离方案审批。
- 处置方案执行未完成时，关联隔离方案的作业申请环节被锁定，禁止发起。
- 处置方案发生变更时，若关联隔离方案尚未进入执行阶段，自动触发隔离方案复核提醒。


#### 7.1.4 盲板作业管理（PC 端）

##### 7.1.4.1 作业申请与审批

- **作业申请发起**：关联隔离方案，选择本次作业涉及的盲板清单。
- **安全措施确认**：逐项确认安全措施（如：泄压、排空、置换、分析合格等），支持勾选确认并签名。
- **JSA/JHA关联**：A级作业强制关联作业安全分析，支持上传分析报告。
- **差异化审批**：根据风险等级自动匹配审批流程和审批人。
- **作业票生成**：审批通过后自动生成标准作业票（含二维码），支持打印和移动端展示。**【PC↔移动端交互】** 作业票生成后推送至移动端，作业人员通过移动端接收并执行。

##### 7.1.4.2 作业监控与调度

- **作业实时监控**：PC 端实时展示各作业票的执行进度、当前所处步骤、Hold Point 完成情况。**【PC↔移动端交互】** 移动端现场执行进度实时回传 PC 端监控大屏。
- **作业调度**：支持作业任务的分配、改派、暂停、取消。
- **作业完工归档**：作业完工后由 PC 端进行归档与完整性验收。

#### 7.1.5 组态管理（隔离点位及盲板组态）

本模块提供隔离点位与盲板的可视化组态能力，实现"画面配置—数据绑定—实时监控"一体化。

##### 7.1.5.1 组态画面编辑器

- **底图导入**：支持上传 P\&ID 图片、导入 CAD（DWG/DXF）、导入三维模型作为画面底图，或在线空白绘制。
- **图元绘制工具**：提供隔离点、管线、设备、阀门、文本标注、隔离边界等图元的绘制与拖拽摆放工具。
- **图元属性配置**：配置图元的位置、大小、颜色、形状、图标、显示标签等样式属性。
- **状态样式映射**：为绑定业务对象的图元配置状态驱动的显示样式，例如：通=绿色、盲=红色、异常=闪烁红、未绑定=灰色。
- **图层与层级管理**：支持图层分组、图元叠放层级调整、显示/隐藏控制。
- **隔离边界绘制**：支持在画面上绘制隔离边界区域（多边形/闭合曲线），标识一组隔离点构成的隔离范围。
- **画面缩放与对齐**：支持画面缩放、平移、网格对齐、标尺辅助。

##### 7.1.5.2 图元与数据绑定

- **隔离点图元绑定**：将隔离点图元绑定至隔离点主数据，绑定后图元实时反映该点位的通盲状态、占用状态、当前安装盲板信息、异常标识。
- **绑定关系校验**：校验图元绑定对象是否存在、是否已被其他图元绑定，避免重复绑定。
- **批量绑定**：支持通过编码批量匹配并绑定图元与业务对象。
- **数据联动预览**：编辑状态下可预览图元在不同状态下的显示效果。

##### 7.1.5.3 组态画面版本与发布

- **版本管理**：画面每次发布生成新版本，历史版本可查看、对比、回滚。
- **编辑/发布分离**：画面有"编辑中"和"已发布"两种状态，编辑不影响在线监控画面，发布后生效。
- **发布审核**：高风险装置的画面发布可配置审核流程，审核通过后方可发布上线。
- **画面停用与替换**：支持画面停用、替换底图、迁移图元绑定关系。

##### 7.1.5.4 组态画面与监控联动

- **画面即监控**：已发布的组态画面直接作为可视化监控画面使用（见 7.1.6），无需二次配置。
- **图元交互**：监控画面中点击图元可查看绑定隔离点的详情、状态历史、关联作业票。
- **多端复用**：组态画面一次配置，PC 端用于监控大屏，移动端用于现场查看（见 7.2.10）。**【PC↔移动端交互】** PC 端发布的组态画面同步至移动端，现场人员可在移动端查看同款画面与点位状态。

#### 7.1.6 盲板可视化监控

##### 7.1.6.1 总览看板

- **全厂隔离状态总览**：显示全厂隔离点总数、在用盲板数、异常状态数、今日作业数等关键指标。
- **风险分布图**：各装置区域的风险等级分布热力图。
- **作业动态**：实时滚动显示当前正在进行的作业及状态。**【PC↔移动端交互】** 作业动态由移动端现场执行实时驱动。
- **预警信息栏**：最新预警信息实时推送，支持点击查看详情。

##### 7.1.6.2 组态画面监控（图纸化监控）

- **流程图模式**：基于已发布的组态画面叠加显示隔离点/盲板状态（通/盲/异常），不同状态用配置的样式标识。
- **三维模型模式**：在三维工厂模型上标注隔离点/盲板位置和状态，支持视角旋转、缩放、点击查看详情。
- **列表模式**：传统列表展示，支持多维筛选和排序。
- **模式切换**：支持在组态流程图、三维模型、列表三种模式间自由切换。

##### 7.1.6.3 预警推送

- **预警规则配置**：支持自定义预警规则（如：盲板超期安装、状态异常、隔离冲突等）。
- **多渠道推送**：系统内消息、移动端推送、短信、企业微信等多渠道通知。
- **预警分级**：按严重程度分为提醒（黄色）、警告（橙色）、严重（红色）三级。
- **预警闭环**：预警触发→推送→确认→处置→关闭，形成完整闭环。**【PC↔移动端交互】** 预警同步推送至移动端，现场人员可在移动端确认与处置。

#### 7.1.7 异常管理与一键停工

##### 7.1.7.1 异常场景分类

| 编号 | 异常类型          | 触发条件                  | 响应措施                   |
| -- | ------------- | --------------------- | ---------------------- |
| E1 | 位置码扫描异常       | 扫码位置与方案指定位置不匹配        | 禁止操作，推送通知给作业负责人，记录异常日志 |
| E2 | 盲板规格不匹配       | 领用盲板规格与隔离点要求不匹配       | 提示更换盲板，系统自动匹配推荐        |
| E3 | 安全措施未全部确认     | 安全措施确认项未全部勾选即进入执行环节   | 强制拦截，提示未完成项            |
| E4 | 隔离冲突检测        | 同一隔离点同时被两个以上的作业方案占用   | 方案审批时即告警，禁止冲突审批        |
| E5 | 盲板超期安装        | 盲板安装时间超过方案设计周期        | 告警推送，通知隔离总负责人          |
| E6 | 状态异常变更        | 盲板状态发生不符合流程的变更        | 系统锁定，需管理人员介入           |
| E7 | Hold Point未确认 | 进入下一步时上一Hold Point未确认 | 强制拦截，禁止跳步              |
| E8 | 作业票超期         | 作业票超过有效期未完工           | 停工告警，需重新审批             |
| E9 | 紧急工况          | 装置异常、泄漏、火灾等紧急情况       | 一键停工，所有关联作业强制终止        |

##### 7.1.7.2 一键停工

- **触发条件**：隔离总负责人或安全管理人员可在 PC 端一键下发停工指令。**【PC↔移动端交互】** 停工指令实时推送至移动端，现场操作界面即时锁定。
- **停工范围**：可按装置、区域、作业票、全厂四级范围下达停工指令。
- **停工效果**：关联作业票自动置为"停工"状态，移动端实时推送停工通知，现场操作被锁定。
- **复工流程**：复工需经过安全检查、原因分析、整改确认、复工审批四步流程。**【PC↔移动端交互】** 复工审批在 PC 端完成，复工通知推送至移动端解除锁定。
- **停工记录**：所有停工事件自动记录，包括触发人、触发时间、原因、范围、复工时间等。

#### 7.1.8 查询统计与报表

- **隔离点台账报表**：支持按装置、区域、分类、状态等条件生成隔离点台账报表。
- **盲板台账报表**：支持按装置、型号、规格、状态等条件生成盲板台账报表。

- **作业完成率分析**：各装置/区域的作业完成率、按时完成率统计。
- **异常事件分析**：异常事件分类统计、趋势分析、根因分析。
- **KPI看板**：实时展示各项KPI指标及达标情况。
- **合规审计报表**：自动生成满足GB 30871-2022审计要求的报表。
- **数据导出**：支持Excel、PDF、CSV等多种格式导出。

##### 7.1.9.1 规则引擎

### 7.2 移动端功能需求

移动端面向作业负责人、作业人员、监护人及需移动审批的管理人员，承担现场执行、扫码校验、状态回传、移动审批、工艺处置确认与消息响应等工作。

#### 7.2.1 工艺处置现场执行

- **处置任务接收**：现场人员通过移动端接收工艺处置任务，查看处置步骤清单、处置方法、验收标准及安全注意事项。**【PC↔移动端交互】** 处置方案审批通过后由 PC 端推送至移动端。
- **处置步骤逐步确认**：按步骤序号引导现场人员逐项执行，每完成一步，录入检测结果（如：可燃气体浓度实测值）、检测方法、检测仪器，确认合格后进入下一步。
- **异常上报**：处置步骤确认不合格时，移动端自动标记异常，支持填写异常说明与处理措施并拍照上传。**【PC↔移动端交互】** 异常信息实时回传 PC 端，触发处置异常告警。
- **处置完工确认**：所有处置步骤确认合格后，移动端提交处置完工确认，电子签名。**【PC↔移动端交互】** 完工确认回传 PC 端，解除隔离方案作业申请锁定。
- **离线支持**：网络中断时支持离线执行并缓存确认记录，网络恢复后自动同步。

#### 7.2.2 扫码操作

- **多码识别**：支持扫描盲板码、隔离点位置码、作业票码、人员码，快速完成各项操作。
- **五码一致校验**：现场扫码时自动执行方案码、位置码、盲板码、作业票码、人员码的一致性校验（详见 7.2.4）。**【PC↔移动端交互】** 校验异常实时回传 PC 端，触发 PC 端异常告警与监控刷新。
- **扫码历史**：记录扫码操作日志，支持回查。

#### 7.2.3 作业任务接收与执行

- **作业任务接收**：作业人员通过移动端接收作业任务，查看作业详情和安全要求。**【PC↔移动端交互】** 作业任务由 PC 端作业审批通过后推送至移动端。
- **现场操作指引**：逐步引导现场操作，每一步提供操作说明和确认提示。
- **标准化作业包**：移动端展示作业任务清单、操作步骤指引、安全措施确认表、Hold Point检查表，引导操作人员逐步完成。
- **每完成一步**，系统自动记录完成时间和操作人，进度实时回传 PC 端。**【PC↔移动端交互】** 执行进度实时回写 PC 端作业监控大屏。

#### 7.2.4 施工位置准确（最后一米防错）

##### 7.2.4.1 五码一致

"五码一致"是本系统防错机制的核心，确保方案、实物、位置三者严格对应：

| 编码类型 | 编码内容         | 来源     |
| ---- | ------------ | ------ |
| 方案码  | 隔离方案中指定安装位置  | 隔离方案   |
| 位置码  | 现场隔离点二维码     | 隔离点主数据 |
| 盲板码  | 盲板实物二维码/RFID | 盲板实物二维码 |
| 作业票码 | 本次作业票编码      | 作业审批系统 |
| 人员码  | 操作人员身份码      | 用户管理   |

##### 7.2.4.2 扫码比对三重校验

| 校验层级    | 操作     | 校验逻辑                             | 异常处理                   |
| ------- | ------ | -------------------------------- | ---------------------- |
| **第一重** | 扫码到达位置 | 扫描位置码，系统比对是否属于本作业票指定的隔离点清单       | 位置不匹配时禁止下一步操作，提示正确位置信息 |
| **第二重** | 扫码领用盲板 | 扫描盲板码，系统比对口径、压力等级、材质是否适配当前隔离点    | 盲板不匹配时提示更换，系统自动匹配推荐    |
| **第三重** | 安装确认扫码 | 同时扫描位置码和盲板码，系统确认"正确的盲板安装到了正确的位置" | 任何一项不匹配则锁定，需管理人员介入解锁   |

#### 7.2.5 现场执行流程

1. **作业交底**：作业负责人对作业人员进行现场交底，确认隔离方案、盲板位置、安全措施。
2. **盲板领用**：扫码领用盲板，系统自动记录领用人、领用时间、领用盲板二维码。
3. **位置到达确认**：到达施工位置后，扫码隔离点二维码，系统自动比对方案指定位置。
4. **盲板安装/拆除**：按规范操作，操作完成后扫码确认，记录操作结果。
5. **Hold Point确认**：关键控制点由监护人/负责人签字确认后方可进入下一步（详见 7.2.6）。
6. **通盲效果确认**：安装完成后进行密封效果检测（压力测试/泄漏检测），记录检测结果。
7. **挂牌标识**：安装完成后挂隔离警示牌，记录挂牌信息。
8. **作业完工确认**：所有盲板操作完成后，作业负责人确认完工，监护人确认签字。**【PC↔移动端交互】** 完工确认回传 PC 端，触发 PC 端归档与完整性验收流程。

> 8 个强制控制点（Hold Point）见 7.2.6。

#### 7.2.6 Hold Point 确认

| 编号      | Hold Point | 确认人          | 确认内容                      | 对应风险等级  |
| ------- | ---------- | ------------ | ------------------------- | ------- |
| **HP1** | 方案交底确认     | 作业负责人        | 所有作业人员已理解方案内容、明确盲板位置和安全措施 | A/B/C/D |
| **HP2** | 盲板领用确认     | 作业负责人        | 领用的盲板型号、规格、材质与方案一致        | A/B/C/D |
| **HP3** | 位置到达确认     | 作业人员         | 扫码确认施工位置与方案指定位置一致（五码校验）   | A/B/C/D |
| **HP4** | 安全措施落实确认   | 监护人          | 泄压、排空、置换、分析结果全部合格         | A/B/C   |
| **HP5** | 盲板安装确认     | 监护人          | 盲板安装方向正确、密封垫片到位、螺栓紧固合格    | A/B/C   |
| **HP6** | 通盲效果确认     | 工艺工程师/监护人    | 密封效果检测合格（压力/泄漏测试）         | A/B     |
| **HP7** | 挂牌标识确认     | 监护人          | 隔离警示牌已正确悬挂，信息清晰可辨         | A/B/C   |
| **HP8** | 完工验收确认     | 隔离总负责人/工艺工程师 | 所有盲板操作完成，现场工完料净场地清        | A/B     |

- 移动端支持在每个 Hold Point 进行检查确认与电子签名。**【PC↔移动端交互】** Hold Point 确认结果实时回传 PC 端，更新作业进度与监控状态；未确认时 PC 端与移动端均强制拦截下一步。

#### 7.2.7 移动端审批

- **方案/作业审批**：管理人员可在移动端完成隔离方案审批、作业票审批，查看方案详情和相关图纸。**【PC↔移动端交互】** PC 端提交的审批单推送至移动端，移动端审批结果实时回写 PC 端流程状态。
- **审批意见留痕**：所有审批意见、修改记录、驳回原因均永久保存。

#### 7.2.8 拍照上传

- 支持现场拍照，自动关联到作业记录（位置确认、安装确认、效果确认等）。**【PC↔移动端交互】** 照片实时上传至 PC 端作业档案与监控画面，供管理人员查看。

#### 7.2.9 消息推送与一键停工响应

- **消息推送**：作业任务、审批通知、预警信息实时推送。**【PC↔移动端交互】** 消息由 PC 端业务事件触发。
- **一键停工响应**：接收 PC 端下发的停工指令，即时锁定操作界面，推送停工通知；复工通知到达后解除锁定。**【PC↔移动端交互】** 停工/复工指令由 PC 端发起，移动端响应执行。

#### 7.2.10 组态画面查看

- **画面查看**：现场人员可在移动端查看 PC 端已发布的组态画面，了解所在装置的隔离点位与盲板实时状态。**【PC↔移动端交互】** 组态画面由 PC 端配置发布，移动端只读查看，状态数据实时同步。
- **图元点击**：点击图元查看绑定隔离点/盲板的详情与状态。

#### 7.2.11 离线模式

- 支持离线缓存作业数据，网络恢复后自动同步。**【PC↔移动端交互】** 离线期间产生的操作记录在网络恢复后回传 PC 端，PC 端据此更新状态与监控。

### 7.3 PC 端与移动端交互总览

| 交互场景          | PC 端动作                  | 移动端动作          | 数据流向          |
| ------------- | ----------------------- | -------------- | ------------- |
| 工艺处置任务下发      | 处置方案审批通过，推送处置任务         | 接收处置任务与步骤清单    | PC → 移动端      |
| 处置执行确认        | 实时展示处置步骤执行进度            | 逐步执行并回传检测结果    | 移动端 → PC      |
| 处置异常上报        | 接收异常信息，触发告警             | 上报不合格检测结果与处理措施 | 移动端 → PC      |
| 处置完工确认        | 解除隔离方案作业申请锁定            | 提交完工确认与电子签名    | 移动端 → PC      |
| 作业任务下发        | 作业审批通过，生成作业票            | 接收作业任务推送       | PC → 移动端      |
| 现场执行进度        | 实时展示执行进度与 Hold Point 状态 | 逐步执行并回传进度      | 移动端 → PC      |
| 五码校验          | 异常时触发告警与监控刷新            | 现场扫码校验         | 移动端 → PC      |
| Hold Point 确认 | 更新作业进度，未确认则拦截           | 现场检查确认与电子签名    | 移动端 → PC      |
| 隔离点状态更新       | 状态台账与组态画面同步刷新           | 安装/拆除操作回传状态    | 移动端 → PC      |
| 移动审批          | 提交审批单                   | 完成审批，结果回写      | PC → 移动端 → PC |
| 拍照上传          | 照片归档至作业档案与监控            | 现场拍照上传         | 移动端 → PC      |
| 预警推送          | 触发预警，多渠道通知              | 接收预警，现场确认处置    | PC → 移动端 → PC |
| 一键停工/复工       | 下发停工/复工指令               | 锁定/解锁操作界面      | PC → 移动端      |
| 组态画面          | 配置并发布组态画面               | 只读查看画面与状态      | PC → 移动端      |
| 冲突检测          | 检测点位占用冲突                | 扫码时若点位锁定则禁止操作  | PC → 移动端      |
| 离线同步          | 网络恢复后接收离线数据             | 离线缓存，联网后同步     | 移动端 → PC      |

## 12. 预期效果

### 12.1 安全管理提升

- **盲板位置错装/漏装率**：预计降低95%以上，通过五码一致校验机制从根本上杜绝位置错误。
- **工艺处置规范执行率**：从依赖人工经验与纸质交底提升至系统化步骤引导与逐项确认，处置步骤漏项率趋零。
- **隔离点位治理规范率**：从无统一治理提升至全生命周期受控，点位新增、变更、停用均流程化、可追溯。
- **隔离方案合规率**：从当前的不足60%提升至100%，系统强制规范方案编制流程，且处置方案完成后方可进入隔离作业。
- **作业流程标准化率**：从当前的参差不齐提升至100%，差异化流程确保各风险等级匹配适当管控。
- **异常事件响应速度**：从小时级提升至分钟级，智能预警实现实时推送。

### 12.2 管理效率提升

- **隔离点台账维护效率**：提升80%以上，从纸质人工维护升级为系统化主数据管理。
- **监控画面配置效率**：组态化配置替代手工标注，画面与数据实时绑定，监控维护成本大幅降低。
- **作业审批效率**：提升50%以上，移动端审批减少流程等待时间。
- **报表生成效率**：提升90%以上，从手工统计报表升级为系统自动生成。
- **合规审计准备时间**：从数天缩短至数分钟，系统自动生成审计报表。

### 12.3 数据价值释放

- 建立完整的隔离点位与盲板作业数据库，为设备管理、维修决策提供数据支撑。
- 积累的作业数据可用于风险分析、趋势预测、持续改进。
- 与周边系统（PTW、DCS、CMMS等）的数据互通，消除信息孤岛。
