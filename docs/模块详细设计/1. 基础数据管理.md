# 基础数据管理

## 7.1.1 盲板主数据

### 界面描述

#### 盲板汇总页
菜单:盲板主数据/盲板驾驶舱
**统计卡片**：页面顶部一排统计卡片，显示盲板总数、在库数、在用数、送检数、报废数、超期数

#### 盲板列表页
菜单:盲板主数据/盲板列表
- **顶部区域**：
  1. 搜索/筛选栏:包含盲板ID输入框、盲板型号下拉选择、DN范围输入（最小值/最大值）、PN范围输入（最小值/最大值）、材质下拉选择、当前状态下拉选择、图标按钮(搜索、重置、导出)
  2. 操作按钮：添加盲板、批量导入、下载模板（批量导入的模板)
  * 新增盲板:盲板基础信息表单,字段见下表
  * 批量导入流程:弹出文件选择窗口 → 选择Excel文件 → 预览导入数据表格 → 确认导入
- **中部区域**：数据表格，列包括盲板ID、盲板型号、DN、PN、材质、当前状态、当前安装位置、下次检验日期、操作列（查看/编辑/报废/打印二维码按钮）
  1. 查看:弹出盲板详情页
- **底部区域**：分页组件，支持每页条数选择（10/20/50/100）

#### 盲板详情页
- **顶部区域**：盲板二维码图片展示及打印按钮
- **主区域**：标签页形式组织
  - 基本信息标签页：展示盲板全部字段信息（只读模式）
  - 安装历史标签页：时间线展示每次安装/拆除记录
  - 检验记录标签页：表格展示定期检验记录(待细化)
  - 状态变更时间线标签页：时间轴展示生命周期状态变更

#### 盲板盘点任务
菜单:盲板主数据/盲板盘点
- **顶部区域**：
  1. 搜索/筛选栏：任务名称输入框（模糊匹配）、任务状态下拉选择（进行中/已完成/已取消）、创建时间范围选择器、创建人输入框、图标按钮（搜索、重置）
  2. 操作按钮：新建盘点任务、导出盘点报告
  * 新建盘点任务流程：弹出任务创建表单 → 填写任务信息 → 选择盘点范围 → 提交创建
- **中部区域**：数据表格，列包括任务名称、盘点范围描述、盲板总数（任务目标数）、已盘点数、完成率（进度条）、任务状态、创建人、创建时间、截止时间、操作列（开始盘点/查看详情/取消任务按钮）
  1. 任务状态列颜色标识：进行中=蓝色、已完成=绿色、已取消=灰色
  2. 完成率列使用进度条+百分比文字展示
  3. 点击"开始盘点"跳转至盘点执行页（移动端扫码界面）
  4. 点击"查看详情"弹出任务详情弹窗
- **底部区域**：分页组件，支持每页条数选择（10/20/50/100）

#### 盘点任务详情弹窗
- **顶部区域**：任务名称、任务状态标签、创建时间、截止时间
- **主区域**：标签页形式组织
  - 基本信息标签页：展示任务全部字段信息（只读模式）
  - 盘点明细标签页：表格展示每条盘点记录，列包括序号、盲板ID、盲板型号、DN、PN、材质、系统记录状态、系统记录位置、盘点结果状态、盘点结果位置、盘点人、盘点时间、差异标记
    * 差异标记列：无差异显示"一致"（绿色），有差异显示"差异"（红色）+ 差异描述图标
  - 差异汇总标签页：仅当存在差异记录时显示，汇总展示所有差异项（遗漏盲板、多余盲板、状态不一致、位置不一致）

#### 移动端盘点执行页
- **扫码区域**：顶部全屏扫码窗口，支持连续扫码
- **已扫列表**：扫码窗口下方展示已扫描的盲板列表（卡片形式），每张卡片显示盲板ID、盲板型号、扫码时间
  * 点击卡片可手动修正盘点状态（在库/在用/送检/报废/丢失）和当前位置
- **底部操作栏**：提交盘点结果按钮、暂存草稿按钮
- **提交确认**：提交前弹出差异预览（如有差异），确认后提交

### 交互流程

#### 新建盘点任务
1. 用户进入"盲板主数据/盲板盘点"菜单
2. 点击"新建盘点任务"按钮
3. 系统弹出任务创建表单
4. 用户填写任务名称、选择盘点范围类型（按装置/按区域/自定义筛选）
5. 根据选择的范围类型，系统展示对应的范围选择控件：
   - 按装置：弹出装置树形多选组件，用户勾选目标装置
   - 按区域：弹出区域树形多选组件，用户勾选目标区域
   - 自定义筛选：展示高级筛选面板，支持按状态、DN范围、PN范围、材质等条件组合筛选
6. 系统实时预览范围内盲板数量，显示在表单底部
7. 用户可选填截止时间
8. 点击"提交"按钮，系统校验后创建任务
9. 创建成功后刷新任务列表，新任务状态为"进行中"

#### 执行盘点（移动端）
1. 盘点人员在移动端打开盘点任务
2. 系统进入扫码界面，调用设备摄像头
3. 盘点人员扫描盲板上的二维码
4. 系统自动匹配盲板ID，显示该盲板的基本信息（型号、DN、PN、材质、系统记录状态、系统记录位置）
5. 盘点人员确认/修正实际状态和位置：
   - 状态与系统一致：直接确认
   - 状态与系统不一致：手动选择实际状态（在库/在用/送检/报废/丢失）
   - 状态为"在用"时：手动选择实际安装位置（从隔离点主数据中引用）
6. 确认后该条记录加入已扫列表
7. 重复步骤3-6，扫描范围内所有盲板
8. 扫描完成后点击"提交盘点结果"
9. 系统进行差异对比，弹出差异预览：
   - 遗漏盲板（范围内但未扫描到的盲板，标记为差异）
   - 状态不一致的盲板
   - 位置不一致的盲板
   - 扫描到但不在范围内的多余盲板（标记为异常）
10. 盘点人员确认差异后点击"确认提交"
11. 系统保存所有盘点明细记录，更新任务完成率和状态

#### 盘点任务详情查看
1. 用户在任务列表中点击某行"查看详情"
2. 系统弹出任务详情弹窗，默认展示"基本信息"标签页
3. 用户切换至"盘点明细"标签页，查看每条盘点记录
4. 差异行以红色高亮显示，可点击差异描述图标查看详细差异说明
5. 用户切换至"差异汇总"标签页（仅存在差异时显示），查看分类汇总的差异清单
6. 差异汇总按差异类型分组展示：遗漏盲板、多余盲板、状态不一致、位置不一致

#### 取消盘点任务
1. 用户在任务列表中点击某行"取消任务"按钮
2. 系统检查任务状态，仅"进行中"的任务可取消
3. 弹出确认对话框，提示"确认取消盘点任务[任务名称]？已盘点的记录将保留"
4. 用户确认后，系统将任务状态更新为"已取消"
5. 记录操作日志

#### 导出盘点报告
1. 用户点击"导出盘点报告"按钮
2. 系统弹出导出选项：
   - 导出当前筛选结果（按当前筛选条件导出任务列表）
   - 导出选中任务的盘点明细（需先勾选目标任务）
3. 选择导出范围后，系统生成Excel文件并下载
4. 导出内容包括：任务基本信息、盘点明细（含差异标记）、差异汇总

#### 盘点结果对比
菜单:盲板主数据/盘点结果对比
- **顶部区域**：
  1. 筛选栏：盘点任务下拉选择（单选已完成的盘点任务）、差异类型下拉多选（遗漏盲板/多余盲板/状态不一致/位置不一致）、装置/区域树形筛选、盲板状态下拉选择、图标按钮（搜索、重置、导出报告）
  2. 统计卡片：盘点盲板总数、一致数、差异数、遗漏数、多余数
  * 统计卡片数字随筛选条件动态更新
- **中部区域**：结果对比表格，列包括盲板ID、盲板型号、DN、PN、材质、系统记录状态、系统记录位置描述、盘点结果状态、盘点结果位置描述、差异类型、盘点人、盘点时间、操作列（查看详情）
  1. 差异类型列颜色标识：无差异=绿色"一致"、状态不一致=橙色、位置不一致=蓝色、状态和位置均不一致=红色
  2. 差异行使用浅色背景高亮区分
  3. 支持按差异类型快速筛选（点击统计卡片联动筛选）
  4. 点击"查看详情"弹出盲板详情页（包含该盲板的系统记录与盘点记录并排对比）
- **底部区域**：分页组件，支持每页条数选择（10/20/50/100）

#### 盘点结果对比详情页
- **顶部区域**：盲板ID、盲板型号，差异标记标签
- **主区域**：左右双栏对比布局
  - 左栏（系统记录）：系统记录状态、系统记录位置、上次检验日期、系统记录更新时间
  - 右栏（盘点结果）：盘点结果状态、盘点结果位置、盘点人、盘点时间
  - 差异字段以红色边框高亮标识
- **底部区域**：
  - "采纳盘点结果"按钮（以盘点结果覆盖系统记录，更新盲板主数据的状态和位置）
  - "忽略差异"按钮（标记差异为已处理但维持系统记录不变，需填写忽略原因）
  - "打印对比报告"按钮

### 交互流程

#### 盘点结果对比查看
1. 用户进入"盲板主数据/盘点结果对比"菜单
2. 系统默认加载最近一次已完成盘点任务的结果对比数据
3. 顶部统计卡片自动汇总当前筛选条件下的各项数量
4. 用户可通过筛选栏切换盘点任务、过滤差异类型、筛选装置/区域范围
5. 点击统计卡片可快速筛选对应差异类型（如点击"差异数"卡片，表格仅显示有差异的记录）
6. 点击某行"查看详情"进入对比详情页

#### 差异处理 - 采纳盘点结果
1. 用户在对比详情页点击"采纳盘点结果"按钮
2. 系统弹出确认对话框，列出将要变更的字段：
   - 状态：系统记录[原值] → 盘点结果[新值]
   - 位置：系统记录[原值] → 盘点结果[新值]
3. 用户确认后，系统执行以下操作：
   - 更新盲板主数据的 current_status 为盘点结果状态
   - 更新盲板主数据的 current_position_id 为盘点结果位置
   - 记录状态变更日志
   - 将该差异记录标记为"已处理"
4. 处理完成后刷新对比页面

#### 差异处理 - 忽略差异
1. 用户在对比详情页点击"忽略差异"按钮
2. 系统弹出忽略原因填写框（必填，文本输入，如"盲板临时借出已归还"）
3. 用户填写原因并确认后，系统将该差异记录标记为"已忽略"
4. 忽略原因保存至差异记录的备注字段

#### 批量处理差异
1. 用户在结果对比表格中勾选多条差异记录（仅差异行可勾选）
2. 表格上方出现批量操作工具栏
3. 用户选择操作：
   - 批量采纳：批量以盘点结果覆盖系统记录
   - 批量忽略：统一填写忽略原因后批量标记为已忽略
4. 系统逐条校验并执行，完成后显示处理结果（成功数、失败数）

#### 导出对比报告
1. 用户点击"导出报告"按钮
2. 系统根据当前筛选条件生成Excel对比报告
3. 报告包含三个Sheet：
   - Sheet1-对比汇总：盘点任务基本信息+统计汇总
   - Sheet2-差异明细：所有差异记录明细（含差异类型、系统值、盘点值）
   - Sheet3-全量明细：全部盘点记录明细（含无差异记录）
