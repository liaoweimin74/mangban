# 系统管理

## 7.10.1 规则引擎

### 菜单全路径

系统管理 / 规则引擎

### 界面描述

#### 规则引擎首页
- **规则分类标签页**：风险等级判定规则、预警规则、审批流程规则
- **规则列表**：表格展示当前分类下的所有规则，列包括规则名称、规则描述、启用状态、最后修改时间、操作列（编辑/启用/禁用/测试）

#### 规则编辑页
- **规则基本信息**：规则名称、规则描述
- **规则条件配置区**：
  - 条件组：支持多条件组合（AND/OR逻辑）
  - 条件类型选择：字段比较、数值范围、枚举匹配等
  - 条件值输入
- **规则动作配置区**：根据规则类型不同显示不同的动作配置
  - 风险等级规则：输出等级（A/B/C/D）
  - 预警规则：预警等级、推送渠道、责任人
  - 审批流程规则：审批层级、审批人角色
- **启用/禁用开关**

#### 规则测试页
- **测试输入区**：输入模拟数据（根据规则类型显示不同的输入表单）
- **执行测试按钮**：点击后按规则逻辑计算
- **测试结果区**：显示规则判定结果和执行过程日志

### 字段描述

#### 规则定义字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| rule_id | 规则ID | varchar(50) | 系统生成（只读） | 是 | 唯一标识 |
| rule_name | 规则名称 | varchar(200) | 用户录入 | 是 | - |
| rule_type | 规则类型 | varchar(20) | 单选 | 是 | 选项：风险等级判定、预警规则、审批流程规则 |
| rule_description | 规则描述 | text | 用户录入 | 否 | - |
| conditions | 条件配置 | json | 结构化配置 | 是 | 条件组，支持AND/OR组合 |
| actions | 动作配置 | json | 结构化配置 | 是 | 规则触发的动作 |
| is_enabled | 是否启用 | boolean | 开关 | 是 | - |
| priority | 优先级 | int | 数字输入 | 是 | 数字越小优先级越高 |
| version | 版本号 | varchar(20) | 系统生成（只读） | 是 | 规则修改时版本递增 |

### 交互流程

#### 风险等级判定规则配置
1. 管理员进入"系统管理/规则引擎"
2. 选择"风险等级判定规则"标签页
3. 系统默认预置ABCD四级判定规则（基于PRD 4.2节）
4. 管理员可编辑已有规则或新增规则
5. 规则编辑：
   - 选择判定条件（如：介质危害等级 = 极度危害）
   - 添加条件组合（AND/OR）
   - 设置输出等级
6. 启用/禁用规则
7. 规则修改后自动生效，影响新提交的方案风险等级判定

#### 预警规则配置
1. 管理员选择"预警规则"标签页
2. 系统默认预置常用预警规则（如盲板超期安装、检验超期等）
3. 管理员可配置：
   - 触发条件（如：安装时间 > 方案设计周期 + N天）
   - 预警等级（提醒/警告/严重）
   - 推送渠道（系统内/移动端/短信/企业微信）
   - 责任人角色
4. 修改后自动生效

#### 审批流程规则配置
1. 管理员选择"审批流程规则"标签页
2. 系统默认预置ABCD四级审批流程（基于PRD 4.3节）
3. 管理员可配置：
   - 每个等级的审批节点数量
   - 每个节点的审批人角色
   - 是否允许多级审批并行
4. 修改后新提交的作业/方案按新规则执行

#### 规则测试
1. 管理员在规则编辑页或规则列表中点击"测试"按钮
2. 系统进入规则测试页
3. 管理员输入模拟数据（如介质、压力、温度等参数）
4. 点击"执行测试"按钮
5. 系统按规则逻辑逐步计算并显示：
   - 每条条件的匹配结果
   - 条件组合的最终判定结果
   - 规则触发的动作
6. 测试结果帮助管理员验证规则逻辑正确性

## 7.10.2 用户角色权限

### 菜单全路径

系统管理 / 用户角色权限

### 界面描述

#### 组织架构管理页
- **左侧**：组织架构树（集团→公司→工厂→部门→班组）
- **右侧**：选中节点的详情和下属用户列表
- **操作**：添加/编辑/删除组织节点，拖拽调整层级

#### 用户管理页
- **筛选栏**：用户名/姓名搜索、状态下拉选择（启用/禁用）、角色下拉选择
- **数据表格**：列包括用户名、姓名、手机号、邮箱、所属组织、角色、状态（启用/禁用）、最后登录时间
- **操作列**：编辑、禁用/启用、密码重置
- **新建用户按钮**：弹出用户创建表单

#### 角色管理页
- **角色列表**：左侧角色列表（系统管理员、隔离总负责人、工艺工程师、安全管理人员、作业负责人、作业人员/监护人、自定义角色）
- **权限配置区**：右侧展示选中角色的权限配置界面
  - 功能权限树：按模块/菜单/按钮层级展示，勾选分配
  - 数据权限配置：按组织/装置范围的数据可见性控制

#### 权限分配界面
- **功能权限树**：树形结构，三级粒度
  - 一级：模块（基础数据管理、隔离方案管理...）
  - 二级：菜单（盲板主数据、装置位置数据...）
  - 三级：按钮/操作（查看、新增、编辑、删除、导入、导出、审批）
- **勾选方式**：勾选父节点自动全选子节点

### 字段描述

#### 用户字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| user_id | 用户ID | varchar(50) | 系统生成 | 是 | 唯一标识 |
| username | 用户名 | varchar(50) | 用户录入 | 是 | 登录账号，唯一 |
| real_name | 姓名 | varchar(100) | 用户录入 | 是 | - |
| password | 密码 | varchar(200) | 用户录入 | 是 | 加密存储 |
| phone | 手机号 | varchar(20) | 用户录入 | 否 | - |
| email | 邮箱 | varchar(100) | 用户录入 | 否 | - |
| org_id | 所属组织 | varchar(50) | 引用 | 是 | 关联表：组织架构

> **引用查询窗口 - 所属组织（组织架构）**
> - **查询方式**：树形导航选择，左侧展开组织架构树（集团→公司→工厂→部门→班组），点击节点选中
> - **列表显示字段**：选中节点后显示组织名称、组织编码、组织类型、上级组织
> - **选中回填**：选中后回填 org_id，同时回显组织全路径名称
| role_id | 角色 | varchar(50) | 引用 | 是 | 关联表：角色

> **引用查询窗口 - 角色（角色表）**
> - **查询字段**：角色名称（模糊匹配）
> - **列表显示字段**：角色ID、角色名称、角色描述、是否内置角色
> - **分页**：每页20条
> - **选中回填**：选中后回填 role_id，同时回显角色名称
| is_enabled | 是否启用 | boolean | 开关 | 是 | - |
| last_login_time | 最后登录时间 | datetime | 系统生成（只读） | - | - |

#### 角色字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| role_id | 角色ID | varchar(50) | 系统生成 | 是 | 唯一标识 |
| role_name | 角色名称 | varchar(100) | 用户录入 | 是 | - |
| role_description | 角色描述 | varchar(500) | 用户录入 | 否 | - |
| is_builtin | 是否内置 | boolean | 系统生成（只读） | 是 | 内置角色不可删除 |
| permissions | 功能权限 | json | 权限树勾选 | 是 | 权限编码列表 |

### 交互流程

#### 用户管理
1. 管理员进入"系统管理/用户角色权限/用户管理"
2. 查看用户列表，可通过筛选条件搜索
3. 点击"新建用户"填写用户信息
4. 选择所属组织和角色
5. 初始密码由系统生成或管理员设置
6. 点击"保存"创建用户
7. 编辑用户：修改用户信息、调整角色
8. 禁用用户：用户无法登录系统
9. 密码重置：重置为随机密码，用户下次登录时强制修改

#### 角色管理
1. 管理员进入"系统管理/用户角色权限/角色管理"
2. 左侧选择已有角色或点击"新建角色"
3. 在右侧权限配置区勾选功能权限：
   - 展开模块树，勾选允许访问的菜单和操作按钮
4. 配置数据权限：
   - 选择数据可见范围（全部/本组织/自定义装置范围）
5. 保存角色配置
6. 内置角色（系统管理员等）不可删除，但可调整权限

#### 组织架构维护
1. 管理员进入"系统管理/用户角色权限/组织架构"
2. 在左侧树中选中父节点
3. 点击"添加子节点"输入组织名称和编码
4. 支持拖拽调整组织层级
5. 删除组织时检查是否有关联用户，有则禁止删除

## 7.10.3 操作日志审计

### 菜单全路径

系统管理 / 操作日志审计

### 界面描述

#### 日志查询页
- **筛选栏**：操作时间范围选择、操作用户输入/选择、操作类型下拉选择（新增/修改/删除/审批/导入/导出/登录/登出/停工/复工等）、操作对象类型下拉选择（盲板/隔离点/方案/作业票/用户/角色等）、操作对象ID输入、IP地址输入
- **数据表格**：列包括日志ID、操作时间、操作用户、用户IP、操作类型、操作对象类型、操作对象ID、操作内容摘要、操作结果（成功/失败）
- **操作列**：查看详情

#### 日志详情弹窗
- **基本信息**：日志ID、操作时间、操作用户、用户IP、用户代理
- **操作信息**：操作类型、操作对象、操作内容（详细描述）
- **变更前后对比**：如为修改操作，展示修改前和修改后的数据对比（JSON Diff格式）
- **关联业务数据**：关联的业务数据ID和链接

#### 审计追踪页
- **业务数据搜索**：输入业务数据ID（盲板ID/作业票ID/方案ID等）
- **时间线展示**：与该业务数据相关的所有操作按时间倒序排列
- **操作链**：展示数据从创建到最后一次修改的完整操作链条

### 字段描述

#### 操作日志字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| log_id | 日志ID | bigint | 系统生成（只读） | 是 | 自增主键 |
| operator | 操作用户 | varchar(50) | 系统生成（只读） | 是 | 关联表：用户管理 |
| operation_time | 操作时间 | datetime | 系统生成（只读） | 是 | - |
| ip_address | IP地址 | varchar(50) | 系统生成（只读） | 是 | - |
| user_agent | 用户代理 | varchar(500) | 系统生成（只读） | 否 | 浏览器/设备信息 |
| operation_type | 操作类型 | varchar(50) | 系统生成（只读） | 是 | 选项：新增、修改、删除、审批通过、审批驳回、导入、导出、登录、登出、停工、复工、报废等 |
| object_type | 操作对象类型 | varchar(50) | 系统生成（只读） | 是 | 选项：盲板、隔离点、方案、作业票、用户、角色、规则等 |
| object_id | 操作对象ID | varchar(100) | 系统生成（只读） | 是 | 操作对象的唯一标识 |
| operation_detail | 操作内容 | text | 系统生成（只读） | 是 | 操作详细描述 |
| change_before | 变更前数据 | json | 系统生成（只读） | 否 | 修改/删除操作记录变更前数据 |
| change_after | 变更后数据 | json | 系统生成（只读） | 否 | 新增/修改操作记录变更后数据 |
| operation_result | 操作结果 | varchar(10) | 系统生成（只读） | 是 | 选项：成功、失败 |
| fail_reason | 失败原因 | varchar(500) | 系统生成（只读） | 否 | 操作失败时的错误信息 |

### 交互流程

#### 日志查询
1. 管理员进入"系统管理/操作日志审计"
2. 设置筛选条件（时间范围、操作人、操作类型等）
3. 点击"查询"按钮
4. 系统展示符合条件的日志列表
5. 日志按操作时间倒序排列
6. 点击某行"查看详情"弹出日志详情

#### 审计追踪
1. 管理员进入"系统管理/操作日志审计/审计追踪"
2. 输入业务数据ID（如盲板ID、作业票ID）
3. 选择业务数据类型
4. 系统展示该业务数据的所有操作记录时间线
5. 时间线展示：从数据创建→每次修改→当前状态的完整链条
6. 每条操作记录可点击查看详情
7. 修改操作显示变更前后的数据对比

#### 日志导出
1. 管理员查询到目标日志后
2. 点击"导出"按钮
3. 选择导出格式（Excel/CSV）
4. 系统导出当前查询结果
5. 导出的日志文件可直接用于合规审计

#### 日志存储与归档
1. 日志实时写入数据库
2. 日志至少保存3年（系统自动清理3年前的历史日志）
3. 支持手动归档：选择时间范围，将日志导出并归档存储
4. 归档后的日志从在线数据库移除，但仍可通过归档文件查询
