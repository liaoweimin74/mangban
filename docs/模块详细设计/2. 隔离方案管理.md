# 隔离方案管理

## 7.2.1 方案编制

### 菜单全路径

隔离方案管理 / 方案编制

### 界面描述

#### 方案编制页
- **顶部区域**：操作按钮区（新建方案、保存草稿、提交审批、预览方案）
- **主区域**：标准化方案编制表单，以分区形式组织
  - **方案基本信息区**：方案名称、关联装置/单元、风险等级（自动判定+手动微调）、方案编制人、编制日期
  - **方案模板区**：提供标准化的隔离方案编制模板，引导用户完整填写
  - **隔离点选择区**：支持从隔离点台账中选择隔离点，系统自动关联介质、压力、温度等工艺参数
  - **盲板建议区**：根据隔离点参数自动推荐适用的盲板型号和规格
  - **图纸附件区**：支持上传PID图、隔离边界图等附件，并在图上标注隔离点位置
- **底部区域**：保存草稿、提交审批按钮

#### 方案版本列表页
- **表格区域**：展示所有历史版本，列包括版本号、修改人、修改时间、变更说明
- **操作列**：查看、版本对比

### 字段描述

#### 方案基本信息字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 约束 | 备注 |
|--------|--------|---------|---------|------|------|------|

> - **查询方式**：树形导航选择，左侧展开工厂→装置→单元树，点击节点选中
> - **列表显示字段**：选中节点后显示节点名称、编码、节点类型
> - **选中回填**：选中后回填 node_id，同时回显节点全路径名称

| risk_level_auto | 自动判定等级 | varchar(10) | 系统生成（只读） | - | - | 系统根据风险等级判定规则自动计算 |
| risk_level_manual | 手动调整等级 | varchar(10) | 用户录入 | 否 | - | 仅当手动调整与自动判定不同时填写 |
| risk_adjust_reason | 调整原因 | varchar(500) | 用户录入 | 否 | 下调等级时必填 | - |
| creator_id | 编制人 | varchar(50) | 系统生成（自动获取当前用户） | 是 | - | 关联表：用户管理
| create_time | 编制日期 | datetime | 系统生成 | 是 | - | 系统自动记录 |
| plan_status | 方案状态 | varchar(20) | 系统生成（只读） | - | - | 选项：草稿、审批中、已通过、已驳回、已冻结、已作废 |
| version | 版本号 | varchar(20) | 系统生成 | 是 | - | 初始为V1.0，修改后递增 |
| description | 方案描述 | text | 用户录入 | 否 | - | 方案总体说明 |

#### 隔离点选择区字段（子表）

> **引用查询窗口 - 隔离点选择（隔离点主数据）**
> - **查询字段**：隔离点ID（模糊匹配）、管线号（模糊匹配）、所属装置（联动装置选择后自动过滤）、公称直径DN（范围输入）、介质名称（模糊匹配）

> - **分页**：每页20条
> - **多选**：支持复选框多选（一个方案可选择多个隔离点）
> - **选中回填**：选中后回填 isolation_point_id，同时自动关联显示管线号、介质名称、DN、PN（只读）

| recommended_blind_qty | 建议数量 | int | 系统生成 | - | 系统推荐数量（默认1） |

### 交互流程

#### 新建方案
1. 用户进入"隔离方案管理/方案编制"菜单
2. 点击"新建方案"按钮
3. 系统加载方案模板，初始化方案基本信息区
4. 用户填写方案名称、选择关联装置/单元
5. 系统根据选择的装置/单元自动关联该区域下的隔离点列表供选择
6. 用户在隔离点选择区勾选本次方案涉及的隔离点
7. 系统自动校验风险等级判定条件，在风险等级区显示自动判定结果
8. 用户如需调整等级，在风险等级区手动修改并填写调整原因
9. 用户上传相关图纸附件（可选）
10. 可随时点击"保存草稿"暂存当前进度
11. 确认无误后点击"提交审批"进入审批流程

#### 盲板建议
1. 用户在隔离点选择区添加隔离点后
2. 系统根据该隔离点的DN、PN、介质等参数
3. 在盲板建议区自动显示推荐盲板型号和规格
4. 如有库存盲板满足条件，直接显示可用于此隔离点的盲板列表
5. 如无合适库存，提示"无匹配库存盲板，请采购"

#### 方案版本管理
1. 已审批通过的方案如需修改，用户点击"变更方案"
2. 系统自动生成新版本号（V1.0→V1.1→V1.2...）
3. 原版本自动冻结，新版本开始编辑
4. 修改完成后重新提交审批
5. 历史版本可在方案版本列表页查看和对比

#### 方案附件关联
1. 用户在图纸附件区点击"上传附件"
2. 选择PID图或隔离边界图文件（支持jpg/png/pdf）
3. 上传成功后，用户可在图上通过拖拽放置标记点
4. 每个标记点关联一个隔离点ID
5. 保存后标记点位置与隔离点关联关系持久化

## 7.2.2 方案审批与版本

### 菜单全路径

隔离方案管理 / 方案审批

### 界面描述

#### 方案审批列表页
- **筛选栏**：方案名称/编号搜索、风险等级下拉选择、方案状态下拉选择（待审批/已通过/已驳回）、提交时间范围选择
- **数据表格**：列包括方案编号、方案名称、风险等级、版本号、提交人、提交时间、当前审批节点、操作列
- **统计卡片**：待审批数、本月提交数、通过率

#### 方案审批详情页
- **方案信息区**：展示方案全部内容（只读），包括基本信息、隔离点清单、图纸附件
- **审批流程区**：展示审批流程图（当前节点高亮），显示各级审批人及审批状态
- **审批操作区**：
  - 审批意见输入框（文本）
  - 审批附件上传（可选）
  - 通过/驳回按钮
  - 如为隔离总负责人，显示风险等级调整控件

### 字段描述

#### 审批记录字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| approval_id | 审批记录ID | varchar(50) | 系统生成（只读） | 是 | 唯一标识 |
| plan_id | 关联方案ID | varchar(50) | 系统生成（只读） | 是 | 关联表：隔离方案 |
| approver_id | 审批人 | varchar(50) | 系统生成（只读） | 是 | 关联表：用户管理 |

> **审批人引用（用户管理）** — 审批流程自动匹配，不涉及手动选择。如需手动指定审批人，弹出查询窗口：
> - **查询字段**：用户名（模糊匹配）、姓名（模糊匹配）、角色（下拉选择）
> - **列表显示字段**：用户名、姓名、手机号、角色名称、所属组织
> - **分页**：每页20条
| approval_level | 审批层级 | int | 系统生成（只读） | 是 | 1=工艺工程师审批，2=安全管理人员审批，3=隔离总负责人审批 |
| approval_action | 审批动作 | varchar(20) | 用户录入 | 是 | 选项：通过、驳回 |
| approval_comment | 审批意见 | text | 用户录入 | 否 | 驳回时建议填写原因 |
| approval_time | 审批时间 | datetime | 系统生成 | 是 | 系统自动记录 |
| attachment | 附件 | file | 文件上传 | 否 | 审批附件 |

### 交互流程

#### 差异化审批流程
1. 方案提交后，系统根据风险等级自动匹配审批流程
   - A级：工艺工程师审批 → 安全管理人员审批 → 隔离总负责人审批（三级）
   - B级：工艺工程师审批 → 隔离总负责人审批（二级）
   - C级：工艺工程师审批（一级）
   - D级：无需审批，直接通过
2. 系统自动通知当前审批节点的审批人

#### PC端审批
1. 审批人进入"隔离方案管理/方案审批"菜单
2. 列表页显示待审批的方案列表
3. 点击某方案进入审批详情页
4. 审批人查看方案完整内容
5. 在审批操作区填写审批意见
6. 点击"通过"或"驳回"
7. 如通过，系统自动流转到下一审批节点或状态变更为"已通过"
8. 如驳回，方案状态变更为"已驳回"，退回编制人修改

#### 移动端审批
1. 审批人收到推送通知
2. 点击通知进入移动端审批页面
3. 可查看方案详情和相关图纸（支持缩放查看）
4. 填写审批意见并提交
5. 操作逻辑与PC端一致

#### 方案版本冻结
1. 审批通过后，系统自动将方案状态置为"已冻结"
2. 冻结后的方案内容不可编辑
3. 如需变更，须发起新版本（见7.2.1方案版本管理）

## 7.2.3 方案与作业关联

### 菜单全路径

隔离方案管理 / 方案与作业关联

### 界面描述

#### 方案关联作业列表页
- **筛选栏**：方案编号/名称搜索、作业票ID搜索
- **数据表格**：列包括方案编号、方案名称、风险等级、关联作业票ID、作业状态、作业完成进度（已执行盲板数/总盲板数）
- **操作列**：查看方案详情、查看作业详情

#### 方案关联详情页
- **方案信息区**：方案基本信息
- **关联作业清单区**：表格展示该方案下所有关联的作业，包括作业票ID、作业状态、盲板清单、执行进度
- **预警信息区**：显示方案变更后未完成作业的预警信息

### 字段描述

#### 方案-作业关联字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 备注 |
|--------|--------|---------|---------|------|
| id | 关联记录ID | int | 系统生成（只读） | 自增主键 |
| plan_id | 方案ID | varchar(50) | 系统生成（只读） | 关联表：隔离方案 |
| work_ticket_id | 作业票ID | varchar(50) | 系统生成（只读） | 关联表：作业票 |
| create_time | 关联时间 | datetime | 系统生成 | - |
| is_active | 是否有效关联 | boolean | 系统生成 | true=有效，false=方案变更后已失效 |

### 交互流程

#### 作业关联方案
1. 在作业申请时，用户选择关联的隔离方案
2. 系统自动将该作业与方案建立关联关系
3. 作业执行时自动关联方案中的隔离点信息和安全要求

#### 方案变更预警
1. 当已审批通过的方案发生版本变更时
2. 系统自动扫描所有关联的未完成作业
3. 对未完成作业触发预警推送，通知作业负责人
4. 在方案关联详情页的预警信息区显示预警列表
5. 作业负责人确认预警后，决定继续执行或重新申请
