# 盲板个体状态台账

## 功能概述

每一块盲板实物拥有独立的生命周期档案，记录从入库到报废的全过程。

### 菜单全路径

盲板个体状态台账 / 盲板档案

### 界面描述

#### 盲板档案列表页
- **筛选栏**：盲板ID搜索、盲板型号下拉选择、DN范围输入、材质下拉选择、生命周期状态下拉选择（正常/到期检验/超期/报废）、当前状态下拉选择（在库/在用/送检/报废/丢失）
- **数据表格**：列包括盲板ID、盲板型号、DN、PN、材质、当前状态、生命周期状态、累计安装次数、累计使用时长、下次检验日期
- **状态列颜色标识**：生命周期状态列使用颜色标识（正常=绿色、到期检验=黄色、超期=红色、报废=灰色）
- **统计卡片区**：盲板总数、正常数、到期检验数、超期数、报废数

#### 盲板档案详情页
- **顶部区域**：盲板二维码图片及打印按钮
- **标签页形式组织**：
  - **基本信息标签页**：盲板全部字段（只读）
  - **安装历史标签页**：时间线组件，按时间倒序展示每次安装/拆除记录
  - **检验记录标签页**：表格展示检验记录，包括检验日期、检验结果、下次检验日期
  - **维修记录标签页**：表格展示维修记录，包括维修时间、维修内容、维修结果
  - **状态变更时间线标签页**：时间轴展示生命周期状态变更（在库→在用→送检→报废等）

### 交互流程

#### 盲板档案查询
1. 用户进入"盲板个体状态台账/盲板档案"菜单
2. 系统加载全部盲板档案列表（分页展示）
3. 用户可通过筛选栏按条件过滤
4. 列表默认按状态更新时间倒序排列
5. 生命周期状态列使用颜色标识，便于快速识别

#### 盲板档案详情查看
1. 用户在列表页点击某行"查看"按钮
2. 系统跳转到盲板档案详情页
3. 默认展示"基本信息"标签页
4. 用户可切换标签页查看安装历史、检验记录、维修记录、状态变更时间线

#### 安装历史时间线
1. 在"安装历史"标签页，系统按时间倒序展示每次操作
2. 每条记录显示：操作类型图标（安装=绿色箭头、拆除=红色箭头、更换=黄色箭头）、操作时间、位置、作业票号
3. 点击某条记录可展开查看详细信息

#### 状态变更时间线
1. 在"状态变更时间线"标签页，系统按时间轴展示生命周期状态变更
2. 每个状态节点显示：变更前状态→变更后状态、变更时间、变更原因
3. 异常状态变更（如直接从在库变为报废）用红色标记

#### 生命周期状态自动判定
1. 系统定时任务每日检查所有在用盲板的 next_inspection_date
2. 距离下次检验日期<30天 → lifecycle_status 更新为"到期检验"
3. 超过下次检验日期 → lifecycle_status 更新为"超期"
4. 超期状态持续触发预警推送
5. 用户完成检验并更新检验日期后 → lifecycle_status 自动恢复为"正常"
