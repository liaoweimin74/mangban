# 盲板作业管理

## 7.4.1 作业申请与审批

### 菜单全路径

盲板作业管理 / 作业申请与审批

### 界面描述

#### 作业申请列表页
- **筛选栏**：作业票ID搜索、方案编号搜索、风险等级下拉选择、作业状态下拉选择（待审批/已通过/已驳回/进行中/已完成/已停工/已超期）、申请时间范围选择
- **数据表格**：列包括作业票ID、关联方案编号、风险等级、作业内容摘要、申请状态、申请时间、申请人、当前审批节点
- **操作列**：查看详情、编辑（仅待审批状态）、撤销申请
- **统计卡片**：待审批作业数、本月作业总数、本月完成数

#### 作业申请表单页
- **关联方案区**：选择关联的隔离方案（D级作业无需关联方案）
- **盲板清单区**：展示本次作业涉及的盲板清单（从方案自动带入或手动添加）
- **安全措施确认区**：逐项列出安全措施确认项，支持勾选确认并签名
  - 安全措施项包括：已泄压确认、已排空确认、已置换确认、气体分析合格、个人防护装备到位等
  - 每项措施包含确认人和确认时间
- **JSA/JHA关联区**：A级作业强制关联作业安全分析报告，支持上传分析报告文件
- **审批流程区**：展示当前作业的审批流程图

#### 作业票详情页
- 展示完整的作业票信息，包括作业票编号（含二维码）
- 打印作业票按钮
- 作业票内容：作业基本信息、盲板清单、安全措施、审批记录、执行进度

### 交互流程

#### 作业申请发起
1. 用户进入"盲板作业管理/作业申请与审批"菜单
2. 点击"新建作业申请"按钮
3. 系统弹出作业申请表单
4. 用户选择关联的隔离方案（D级可不选）
5. 如关联方案，系统自动带入方案中的隔离点和盲板清单
6. 如为D级作业，用户手动输入作业内容并选择盲板
7. 用户填写计划开始/结束时间
8. 系统根据风险等级动态显示安全措施确认项列表
9. 用户逐项确认安全措施（勾选+自动签名）
10. 如为A级作业，强制上传JSA/JHA分析报告
11. 点击"提交申请"按钮
12. 系统根据风险等级自动匹配审批流程，通知审批人

#### 作业审批
1. 审批人收到审批通知（系统内+移动端推送）
2. 审批人点击通知进入审批详情页
3. 查看作业申请内容、安全措施确认情况、盲板清单
4. 填写审批意见
5. 点击"通过"或"驳回"
6. 审批通过后，系统自动生成标准作业票（含二维码）
7. 作业票状态变为"已通过"
8. 申请人和作业负责人收到通知

#### 作业票查看与打印
1. 用户进入作业票详情页
2. 系统展示完整作业票信息
3. 顶部显示作业票二维码
4. 点击"打印"按钮，系统生成标准格式作业票PDF
5. 支持蓝牙打印机现场打印

## 7.4.2 现场执行流程

### 菜单全路径

盲板作业管理 / 现场执行

### 界面描述（移动端优先）

#### 作业任务接收页
- **作业任务卡片列表**：展示分配给当前用户的作业任务
- 每张卡片显示：作业票ID、关联方案、风险等级、作业内容、计划时间
- 任务状态标识：待接收、进行中、已完成

#### 作业执行引导页
- **步骤导航**：顶部显示当前进度（步骤指示器，如1/8）
- **操作指引区**：当前步骤的操作说明和指引文字
- **操作确认区**：根据当前步骤提供对应的操作界面（扫码、表单、签名等）
- **底部按钮**：上一步/下一步（受Hold Point控制）

### 字段描述

#### 现场执行步骤状态字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 备注 |
|--------|--------|---------|---------|------|
| work_ticket_id | 作业票ID | varchar(50) | 系统生成（只读） | 关联表：作业票 |
| step_no | 步骤序号 | int | 系统生成（只读） | 1~8（取决于风险等级） |
| step_name | 步骤名称 | varchar(100) | 系统生成（只读） | - |
| step_status | 步骤状态 | varchar(20) | 系统生成（只读） | 选项：待执行、进行中、已完成、已跳过 |
| operator | 操作人 | varchar(50) | 用户录入 | - |
| operation_time | 操作时间 | datetime | 系统生成 | - |
| remark | 备注 | text | 用户录入 | - |

### 交互流程

#### 1. 作业交底
1. 作业负责人打开作业任务
2. 系统展示隔离方案内容、盲板位置清单、安全措施
3. 作业负责人对作业人员进行现场交底
4. 所有作业人员确认理解后，作业负责人在移动端签字确认
5. 系统记录交底完成时间和交底人

#### 2. 盲板领用
1. 作业人员扫描盲板上的二维码
2. 系统自动识别盲板ID
3. 系统比对盲板型号、规格、压力等级是否与方案要求一致
4. 匹配成功 → 领用确认，记录领用人、领用时间、领用盲板ID
5. 匹配失败 → 提示"盲板不匹配"，系统推荐可用盲板库存

#### 3. 位置到达确认
1. 作业人员到达施工位置
2. 扫描隔离点位置二维码
3. 系统自动比对是否属于本作业票指定的隔离点清单
4. 位置匹配 → 确认到达，记录到达时间
5. 位置不匹配 → 禁止下一步操作，提示正确的隔离点位置信息

#### 4. 盲板安装/拆除
1. 作业人员按规范操作（安装或拆除盲板）
2. 操作完成后，同时扫描盲板码和位置码
3. 系统执行第三重校验：确认"正确的盲板安装到了正确的位置"
4. 校验通过 → 记录操作结果（操作类型、操作前状态、操作后状态）
5. 校验失败 → 锁定操作，需管理人员介入解锁

#### 5. Hold Point确认
1. 到达Hold Point节点时，系统自动暂停流程
2. 显示当前的Hold Point确认项
3. 责任确认人（监护人/负责人）逐项确认
4. 确认完成后电子签名
5. 系统记录确认时间和确认人
6. 确认通过后方可进入下一步

#### 6. 通盲效果确认
1. 安装完成后，进行密封效果检测
2. 用户选择确认方式（压力测试/泄漏检测/目视检查）
3. 填写检测结果（合格/不合格/待确认）
4. 如有检测数据，填写检测压力值、泄漏率
5. 拍照上传检测过程照片
6. 确认人签字完成

#### 7. 挂牌标识
1. 安装完成后，悬挂隔离警示牌
2. 用户输入挂牌编号或扫描挂牌二维码
3. 拍照上传挂牌照片
4. 确认挂牌信息清晰可辨

#### 8. 作业完工确认
1. 所有盲板操作完成后，作业负责人确认完工
2. 系统检查所有步骤是否已完成
3. 如存在未完成步骤，提示"以下步骤尚未完成：[列表]"
4. 所有步骤完成后，监护人确认签字
5. 作业状态变更为"已完成"
6. 系统自动更新盲板状态和隔离点通盲状态

## 7.4.3 Hold Point管理

### 菜单全路径

盲板作业管理 / Hold Point管理

### 界面描述

#### Hold Point列表页
- **筛选栏**：作业票ID搜索、风险等级下拉选择、Hold Point编号下拉选择、确认状态下拉选择（待确认/已确认/未通过）
- **数据表格**：列包括作业票ID、Hold Point编号、Hold Point名称、风险等级、确认人、确认状态、确认时间
- **状态颜色标识**：待确认=黄色、已确认=绿色、未通过=红色

#### Hold Point确认详情页（移动端）
- **确认项列表**：逐项展示当前Hold Point的确认内容
- **签名区**：电子签名板
- **拍照区**：现场照片上传
- **备注区**：特殊情况说明

### 字段描述

#### Hold Point记录字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| hp_id | 记录ID | int | 系统生成 | 是 | 自增主键 |
| work_ticket_id | 作业票ID | varchar(50) | 系统生成（只读） | 是 | 关联表：作业票 |
| hp_no | Hold Point编号 | varchar(10) | 系统预设 | 是 | 选项：HP1~HP8 |
| hp_name | Hold Point名称 | varchar(100) | 系统预设 | 是 | - |
| confirm_role | 确认人角色 | varchar(50) | 系统预设 | 是 | 根据风险等级和HP编号自动匹配 |
| confirm_person | 确认人 | varchar(50) | 用户录入 | 否 | 实际确认人 |
| confirm_status | 确认状态 | varchar(20) | 用户录入 | 是 | 选项：待确认、已确认、未通过 |
| confirm_time | 确认时间 | datetime | 系统生成 | 否 | - |
| signature | 电子签名 | image | 手写签名 | 否 | - |
| photo | 现场照片 | file | 拍照上传 | 否 | - |
| remark | 备注 | text | 用户录入 | 否 | - |

### 交互流程

#### Hold Point强制管控
1. 系统根据风险等级确定该作业需要执行的Hold Point数量
   - A级：HP1~HP8（8个）
   - B级：HP1~HP5（5个）
   - C级：HP1~HP4（4个）
   - D级：HP1~HP2（2个）
2. 每个Hold Point在对应步骤完成后自动触发
3. 当前Hold Point未确认时，"下一步"按钮置灰
4. 确认人完成确认后，系统解锁下一步

#### Hold Point确认操作
1. 到达Hold Point节点时，系统显示确认项列表
2. 确认人逐项检查确认内容
3. 每项确认通过后勾选
4. 所有项目确认完成后，确认人在电子签名板上签名
5. 拍照上传现场照片（可选）
6. 点击"确认完成"提交
7. 如某项确认不合格，选择"未通过"并填写原因
8. 未通过时触发异常流程，通知作业负责人处理

#### Hold Point跳步拦截
1. 如作业人员尝试跳过未完成的Hold Point
2. 系统强制拦截，弹出提示"HP[n]尚未确认，请先完成确认"
3. 提示当前未完成的Hold Point编号和名称
4. 引导用户返回确认流程
