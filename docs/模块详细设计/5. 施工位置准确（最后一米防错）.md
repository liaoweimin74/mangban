# 施工位置准确（最后一米防错）

## 7.5.1 五码一致

### 菜单全路径

施工位置准确 / 五码一致校验

### 界面描述

#### 五码校验监控页
- **校验统计卡片区**：今日校验总次数、校验通过次数、校验失败次数、通过率
- **校验记录表格**：列包括校验时间、作业票ID、方案码、位置码、盲板码、作业票码、人员码、校验结果（通过/失败）、失败原因
- **校验详情弹窗**：点击某条记录弹出详细校验信息，展示五码的匹配过程

### 字段描述

#### 五码定义

| 编码类型 | 编码内容 | 数据来源 | 校验时机 |
|---------|---------|---------|---------|
| 方案码 | 隔离方案中指定安装位置ID | 隔离方案（plan_id + isolation_point_id） | 作业开始前 |
| 位置码 | 现场隔离点二维码内容 | 隔离点主数据（isolation_point_id） | 位置到达扫码时 |
| 盲板码 | 盲板实物二维码/RFID内容 | 盲板主数据（blind_id + qr_code） | 领用和安装扫码时 |
| 作业票码 | 本次作业票编码 | 作业票（work_ticket_id） | 作业全流程 |
| 人员码 | 操作人员身份码 | 用户管理（user_id） | 每次关键操作确认时 |

### 交互流程

#### 五码一致校验流程
1. **方案编制阶段**：方案中指定隔离点 → 生成方案码
2. **作业申请阶段**：作业票生成 → 关联方案 → 生成作业票码
3. **位置到达阶段**：扫码位置码 → 系统比对位置码是否在方案码清单中
4. **盲板领用阶段**：扫码盲板码 → 系统比对盲板规格是否匹配位置要求
5. **安装确认阶段**：同时扫描位置码+盲板码 → 系统确认"正确的盲板到正确的位置"
6. **人员确认阶段**：扫码人员码或自动获取当前登录用户 → 记录操作人
7. **五码全部校验通过** → 操作允许继续
8. **任一码校验失败** → 操作被拦截

## 7.5.2 扫码比对三重校验

### 菜单全路径

施工位置准确 / 扫码比对校验

### 界面描述

#### 三重校验状态页
- **作业流程进度图**：展示当前作业的三重校验进度
  - 第一重（位置到达校验）：通过/未通过/未执行
  - 第二重（盲板领用校验）：通过/未通过/未执行
  - 第三重（安装确认校验）：通过/未通过/未执行
- **校验失败记录**：表格展示校验失败的记录及处理状态

### 字段描述

#### 三重校验规则

| 校验层级 | 操作节点 | 校验逻辑 | 输入 | 输出 | 异常处理 |
|---------|---------|---------|------|------|---------|
| 第一重 | 位置到达 | 扫描位置码 → 是否属于本作业票指定的隔离点清单 | 位置码内容 | 匹配/不匹配 | 不匹配时禁止下一步，提示正确位置 |
| 第二重 | 盲板领用 | 扫描盲板码 → 型号、规格、压力等级是否适配当前隔离点 | 盲板码内容 | 适配/不适配 | 不适配时提示更换，推荐可用盲板 |
| 第三重 | 安装确认 | 同时扫描位置码+盲板码 → 正确的盲板在正确的位置 | 位置码+盲板码 | 一致/不一致 | 不一致则锁定，需管理人员介入 |

### 交互流程

#### 第一重校验：位置到达
1. 作业人员到达施工位置
2. 打开移动端扫码功能
3. 扫描现场隔离点位置二维码
4. 系统读取位置码中的 isolation_point_id
5. 系统查询当前作业票关联的隔离点清单
6. 比对结果：
   - 位置码在清单中 → 校验通过，提示"位置确认成功"，记录到达时间
   - 位置码不在清单中 → 校验失败，提示"当前位置不属于本作业票范围"，并显示正确的隔离点位置信息

#### 第二重校验：盲板领用
1. 作业人员领用盲板
2. 扫描盲板实物二维码
3. 系统读取盲板码中的 blind_id
4. 系统查询盲板主数据获取型号、DN、PN、材质等信息
5. 系统比对盲板参数与隔离点要求：
   - 盲板DN是否等于隔离点DN
   - 盲板PN是否≥隔离点PN
   - 盲板材质的耐腐蚀性是否满足介质要求
6. 比对结果：
   - 全部匹配 → 校验通过，记录领用信息
   - 不匹配 → 提示具体不匹配项（如"盲板DN150不匹配，需要DN100"），系统推荐可用库存盲板

#### 第三重校验：安装确认
1. 作业人员完成盲板安装操作
2. 同时扫描位置码和盲板码（或依次扫描）
3. 系统执行最终一致性校验：
   - 位置码是否属于本作业票
   - 盲板码是否为本作业领用的盲板
   - 盲板参数是否匹配隔离点要求
4. 校验结果：
   - 全部一致 → 校验通过，记录安装完成
   - 任一项不一致 → 系统锁定操作，弹出详细不一致信息
   - 锁定后需作业负责人或管理人员输入解锁密码/审批后才能继续

## 7.5.3 标准化作业包

### 菜单全路径

施工位置准确 / 标准化作业包

### 界面描述

#### 作业包列表页
- **筛选栏**：作业票ID搜索、风险等级下拉选择、作业状态下拉选择
- **数据表格**：列包括作业票ID、作业包名称、风险等级、任务总数、已完成数、进度百分比、生成时间
- **操作列**：查看作业包、打印作业包

#### 作业包详情页（移动端优先）
- **顶部区域**：作业票基本信息（作业票ID、关联方案、风险等级、计划时间）
- **任务清单区**：逐项列出作业任务，每项包含：
  - 任务编号、任务描述
  - 操作步骤指引（图文结合）
  - 安全措施确认表（勾选框）
  - Hold Point检查表
  - 完成状态标识（未开始/进行中/已完成）
- **底部区域**：整体进度条和完成统计

### 字段描述

#### 作业包任务项字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 备注 |
|--------|--------|---------|---------|------|
| task_no | 任务编号 | varchar(20) | 系统生成（只读） | 如 T1、T2... |
| task_name | 任务名称 | varchar(200) | 系统生成（只读） | - |
| task_description | 任务描述 | text | 系统生成（只读） | 操作指引文本 |
| safety_measures | 安全措施 | text | 系统生成（只读） | 该任务相关的安全措施 |
| hp_required | 是否需要Hold Point | boolean | 系统生成（只读） | - |
| task_status | 任务状态 | varchar(20) | 系统生成（只读） | 选项：未开始、进行中、已完成 |
| completed_time | 完成时间 | datetime | 系统生成（只读） | - |
| completed_by | 完成人 | varchar(50) | 系统生成（只读） | - |

### 交互流程

#### 作业包自动生成
1. 作业审批通过后，系统自动生成标准化作业包
2. 作业包内容根据风险等级和关联方案自动组装：
   - 从方案中提取隔离点清单和盲板要求
   - 根据风险等级生成对应的操作步骤
   - 匹配对应的安全措施确认项
   - 匹配对应的Hold Point检查表
3. 作业包生成后，自动推送到作业负责人和作业人员的移动端

#### 移动端作业包执行
1. 作业人员打开作业包
2. 系统按顺序展示任务清单
3. 当前任务高亮显示，其他任务置灰
4. 每个任务包含详细的操作步骤指引
5. 完成当前任务后，系统自动记录完成时间和操作人
6. 如当前任务涉及Hold Point，自动触发Hold Point确认流程
7. 所有任务完成后，作业包状态变更为"已完成"
8. 作业包执行记录归入作业档案
