# 异常管理与一键停工

## 7.6.1 异常场景分类

### 菜单全路径

异常管理 / 异常事件

### 界面描述

#### 异常事件列表页
- **统计卡片区**：今日异常总数、待处理数、处理中数、已关闭数
- **筛选栏**：异常类型下拉选择（E1~E10）、异常等级下拉选择（提醒/警告/严重）、处理状态下拉选择（待处理/处理中/已关闭）、时间范围选择
- **数据表格**：列包括异常编号、异常类型、异常等级、触发时间、关联作业票ID、关联盲板ID、异常描述、处理状态、处理人
- **颜色标识**：严重=红色背景、警告=橙色背景、提醒=黄色背景

#### 异常详情弹窗/页
- **异常基本信息**：异常类型、触发条件、触发时间、关联数据
- **处理记录区**：时间线展示处理过程
- **处理操作区**：处理意见输入、处理结果选择、附件上传

### 字段描述

#### 异常事件字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| event_id | 异常编号 | varchar(50) | 系统生成（只读） | 是 | 系统自动生成 |
| event_type | 异常类型 | varchar(20) | 系统生成（只读） | 是 | 选项：E1~E10（见异常场景分类表） |
| event_level | 异常等级 | varchar(20) | 系统生成（只读） | 是 | 选项：提醒(黄色)、警告(橙色)、严重(红色) |
| trigger_time | 触发时间 | datetime | 系统生成（只读） | 是 | - |
| source | 异常来源 | varchar(50) | 系统生成（只读） | 是 | 触发异常的模块/操作 |
| related_ticket_id | 关联作业票ID | varchar(50) | 系统生成（只读） | 否 | 如有关联 |
| related_blind_id | 关联盲板ID | varchar(50) | 系统生成（只读） | 否 | 如有关联 |
| related_point_id | 关联隔离点ID | varchar(50) | 系统生成（只读） | 否 | 如有关联 |
| description | 异常描述 | text | 系统生成（只读） | 是 | 系统根据异常类型自动生成描述 |
| process_status | 处理状态 | varchar(20) | 系统生成（只读） | 是 | 选项：待处理、处理中、已关闭 |
| processor | 处理人 | varchar(50) | 用户录入 | 否 | - |
| process_result | 处理结果 | varchar(200) | 用户录入 | 否 | - |
| process_time | 处理时间 | datetime | 系统生成 | 否 | - |

### 交互流程

#### 异常自动检测与触发
1. 系统各模块运行时持续监测异常条件
2. 满足任一异常触发条件时，系统自动创建异常事件记录
3. 根据异常类型自动判定异常等级
4. 异常事件推送到相关责任人
5. 在总览看板的预警信息栏实时显示

#### 异常场景对照表

| 编号 | 异常类型 | 触发条件 | 异常等级 | 响应措施 |
|------|---------|---------|---------|---------|
| E1 | 位置码扫描异常 | 扫码位置与方案指定位置不匹配 | 严重 | 禁止操作，推送通知给作业负责人，记录异常日志 |
| E2 | 盲板型号不匹配 | 领用盲板规格与隔离点要求不匹配 | 警告 | 提示更换盲板，系统推荐可用库存 |
| E3 | 安全措施未全部确认 | 安全措施确认项未全部勾选即进入执行环节 | 严重 | 强制拦截，提示未完成项 |
| E4 | 隔离冲突检测 | 同一隔离点同时被两个以上作业方案占用 | 严重 | 方案审批时即告警，禁止冲突审批 |
| E5 | 盲板超期安装 | 盲板安装时间超过方案设计周期 | 警告 | 告警推送，通知隔离总负责人 |
| E6 | 状态异常变更 | 盲板状态发生不符合流程的变更 | 严重 | 系统锁定，需管理人员介入 |
| E7 | 盲板检验超期 | 在用盲板超过检验有效期 | 提醒 | 告警推送，触发更换流程 |
| E8 | Hold Point未确认 | 进入下一步时上一Hold Point未确认 | 警告 | 强制拦截，禁止跳步 |
| E9 | 作业票超期 | 作业票超过有效期未完工 | 严重 | 停工告警，需重新审批 |
| E10 | 紧急工况 | 装置异常、泄漏、火灾等紧急情况 | 严重 | 一键停工，所有关联作业强制终止 |

#### 异常处理流程
1. 异常事件生成后，状态为"待处理"
2. 相关责任人收到推送通知
3. 责任人进入异常详情页查看异常信息
4. 根据异常类型执行相应处理措施
5. 填写处理结果和说明
6. 将异常状态更新为"已关闭"
7. 处理记录归入审计日志

## 7.6.2 一键停工

### 菜单全路径

异常管理 / 一键停工

### 界面描述

#### 停工指令下发页
- **停工范围选择区**：
  - 全厂停工（大红色按钮，需二次确认）
  - 按装置选择（装置列表勾选）
  - 按区域选择（区域列表勾选）
  - 按作业票选择（作业票列表勾选）
- **停工原因填写区**：原因类型下拉选择（紧急工况/泄漏/火灾/其他）、详细原因文本输入
- **确认操作区**：停工指令下发按钮（需二次确认弹窗）

#### 停工状态监控页
- **停工事件列表**：表格展示历史停工事件，列包括停工编号、停工范围、停工原因、触发人、触发时间、复工状态
- **当前停工范围展示**：可视化展示当前处于停工状态的装置/区域

#### 复工流程页
- **复工步骤指示器**：四步流程（安全检查→原因分析→整改确认→复工审批）
- **当前步骤操作区**：根据当前步骤显示对应的表单

### 字段描述

#### 停工事件字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| shutdown_id | 停工编号 | varchar(50) | 系统生成（只读） | 是 | 唯一标识 |
| shutdown_scope | 停工范围 | varchar(20) | 用户录入 | 是 | 选项：全厂、装置、区域、作业票 |
| scope_detail | 范围详情 | text | 用户录入 | 是 | 具体的装置/区域/作业票ID列表 |
| reason_type | 原因类型 | varchar(50) | 单选 | 是 | 选项：紧急工况、泄漏、火灾、爆炸、人员伤亡、其他 |
| reason_detail | 详细原因 | text | 用户录入 | 是 | - |
| trigger_id | 触发人 | varchar(50) | 系统生成（自动获取当前用户） | 是 | 关联表：用户管理 |
| trigger_time | 触发时间 | datetime | 系统生成 | 是 | - |
| shutdown_status | 停工状态 | varchar(20) | 系统生成（只读） | 是 | 选项：停工中、复工中、已复工 |

### 交互流程

#### 停工指令下发
1. 隔离总负责人或安全管理人员进入"异常管理/一键停工"菜单
2. 选择停工范围（全厂/装置/区域/作业票）
3. 如选择装置/区域/作业票，勾选具体对象
4. 选择原因类型并填写详细原因
5. 点击"下发停工指令"按钮
6. 系统弹出二次确认对话框，显示停工范围和原因摘要
7. 确认后，系统执行停工操作：
   - 关联作业票自动置为"停工"状态
   - 移动端实时推送停工通知
   - 现场操作界面被锁定（仅显示停工通知）
   - 停工事件记录写入审计日志
8. 页面跳转到停工状态监控页

#### 停工后操作锁定
1. 停工指令下发后，受影响范围内的移动端立即收到推送
2. 作业人员打开移动端时，操作界面被锁定
3. 界面显示：红色背景、"装置已停工"字样、停工原因、停工时间、联系人信息
4. 所有扫码操作和状态变更功能被禁用
5. 只有"查看停工通知"功能可用

#### 复工流程
1. 复工条件满足后，由隔离总负责人发起复工
2. 复工流程分四步，严格顺序执行：
   - **第一步：安全检查** → 填写安全检查结果，上传检查报告
   - **第二步：原因分析** → 填写异常根因分析报告
   - **第三步：整改确认** → 填写整改措施和确认结果
   - **第四步：复工审批** → 隔离总负责人审批确认复工
3. 每步完成后自动进入下一步
4. 复工审批通过后：
   - 关联作业票状态恢复为"待执行"或"进行中"
   - 移动端锁定解除
   - 现场操作恢复正常
   - 系统记录复工时间和复工审批人
