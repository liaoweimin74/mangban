# 盲板可视化监控

## 7.7.1 总览看板

### 菜单全路径

可视化监控 / 总览看板

### 界面描述

#### 看板布局
- **顶部KPI指标行**：横向排列关键指标卡片
  - 全厂盲板总数（数字+趋势箭头）
  - 在用盲板数（数字+占比）
  - 异常状态数（红色数字+闪烁）
  - 今日作业数（数字+完成数/总数）
  - 今日预警数（数字）
- **中部图表区**：
  - **风险分布热力图**：按装置区域划分的网格图，颜色深浅表示风险等级分布
  - **作业动态滚动区**：实时滚动显示当前正在进行的作业及状态（作业票ID、内容摘要、当前步骤、状态）
- **底部预警信息栏**：
  - 最新预警信息列表（实时推送）
  - 每条显示：预警等级图标、预警内容、触发时间、查看详情链接
  - 点击查看详情跳转到对应预警记录

### 字段描述

#### KPI指标字段

| 指标名 | 中文名 | 数据类型 | 数据来源 | 计算方式 |
|--------|--------|---------|---------|---------|
| total_blind_count | 盲板总数 | int | 盲板主数据 | 统计所有盲板记录数 |
| in_use_count | 在用盲板数 | int | 盲板主数据 | 统计current_status='在用'的记录数 |
| abnormal_count | 异常状态数 | int | 点位通盲状态 | 统计is_abnormal=true的记录数 |
| today_ticket_count | 今日作业数 | int | 作业票 | 统计当天创建的作业票数 |
| today_ticket_completed | 今日完成数 | int | 作业票 | 统计当天work_status='已完成'的作业票数 |
| today_alert_count | 今日预警数 | int | 预警记录 | 统计当天生成的预警数 |

### 交互流程

1. 用户进入"可视化监控/总览看板"菜单
2. 系统加载所有KPI数据并展示
3. KPI指标卡片每30秒自动刷新
4. 风险分布热力图展示各装置区域的风险等级分布
5. 鼠标悬停在热力图单元格上，显示该区域的具体数据
6. 作业动态区实时滚动更新
7. 预警信息栏实时推送最新预警
8. 点击预警条目可跳转到详情页面
9. 支持全屏展示模式（适合大屏监控）

## 7.7.2 图纸化监控

### 菜单全路径

可视化监控 / 图纸化监控

### 界面描述

#### 模式切换区
- **顶部工具栏**：
  - 模式切换按钮组（流程图模式、三维模型模式、列表模式）
  - 装置/区域下拉选择（切换查看范围）
  - 筛选条件（状态筛选、介质筛选）
  - 刷新按钮、全屏按钮

#### 流程图模式
- 在PID图或工艺流程图上方叠加显示盲板状态标记
- 标记点使用不同颜色表示状态：通=绿色、盲=红色、异常=黄色闪烁
- 标记点旁显示隔离点ID和盲板ID
- 支持缩放和平移
- 点击标记点弹出信息卡片

#### 三维模型模式
- 嵌入三维工厂模型
- 盲板位置以三维标记点形式标注
- 支持视角旋转、缩放、平移
- 支持预设视角切换（俯视图、侧视图、指定装置视角）
- 点击标记点弹出信息卡片
- 支持框选区域查看详情

#### 列表模式
- 传统表格展示，列包括隔离点ID、管线号、介质、当前通盲状态、当前盲板ID、盲板型号、最近操作时间
- 支持多维筛选和排序
- 状态列颜色标识同点位通盲状态台账

### 字段描述

#### 图纸标注点字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 备注 |
|--------|--------|---------|---------|------|
| point_id | 隔离点ID | varchar(50) | 系统生成（只读） | 关联表：隔离点主数据 |
| marker_x | 标注X坐标 | decimal(10,2) | 系统生成（只读） | 在图纸/模型中的X位置 |
| marker_y | 标注Y坐标 | decimal(10,2) | 系统生成（只读） | 在图纸/模型中的Y位置 |
| marker_z | 标注Z坐标 | decimal(10,2) | 系统生成（只读） | 在三维模型中的Z位置 |
| current_status | 当前通盲状态 | varchar(20) | 系统生成（只读） | 决定标记点颜色 |
| is_abnormal | 是否异常 | boolean | 系统生成（只读） | 决定是否闪烁 |

### 交互流程

#### 模式切换
1. 用户进入"可视化监控/图纸化监控"菜单
2. 默认显示流程图模式（如有PID图数据）
3. 用户点击"三维模型"按钮切换到三维模式
4. 点击"列表"按钮切换到列表模式
5. 切换时保持当前筛选条件不变

#### 流程图模式交互
1. 系统加载当前装置的PID图或工艺流程图
2. 在图上叠加显示所有隔离点的标记点
3. 标记点颜色随状态实时更新
4. 用户可缩放和平移查看不同区域
5. 点击标记点弹出信息卡片，显示：隔离点ID、管线号、介质、当前状态、盲板ID、最近操作时间
6. 信息卡片底部提供"查看详情"链接，点击跳转到隔离点详情

#### 三维模型模式交互
1. 系统加载三维工厂模型
2. 所有隔离点以三维标记点形式标注
3. 用户可通过鼠标拖拽旋转视角，滚轮缩放
4. 预设视角按钮快速定位到指定装置
5. 点击标记点弹出信息卡片（同流程图模式）
6. 支持框选：按住鼠标拖拽框选区域，显示该区域内所有隔离点的汇总信息

#### 列表模式交互
1. 传统表格展示，支持分页
2. 筛选栏支持按装置/区域、介质、状态等条件过滤
3. 点击表头列可排序
4. 点击行查看详情

## 7.7.3 预警推送

### 菜单全路径

可视化监控 / 预警管理

### 界面描述

#### 预警列表页
- **筛选栏**：预警等级下拉选择（提醒/警告/严重）、预警状态下拉选择（待确认/处理中/已关闭）、预警类型下拉选择、时间范围选择
- **数据表格**：列包括预警编号、预警等级、预警类型、预警内容、触发时间、确认状态、确认人、确认时间、处理状态
- **颜色标识**：严重=红色背景、警告=橙色背景、提醒=黄色背景、未确认=加粗

#### 预警详情弹窗/页
- **预警基本信息**：预警等级、类型、触发时间、关联对象
- **预警处理区**：确认按钮、处理意见输入、处理结果选择
- **处理时间线**：展示预警从触发到关闭的完整处理过程

### 字段描述

#### 预警记录字段

| 字段名 | 中文名 | 数据类型 | 编辑类型 | 必填 | 备注 |
|--------|--------|---------|---------|------|------|
| alert_id | 预警编号 | varchar(50) | 系统生成（只读） | 是 | 唯一标识 |
| alert_level | 预警等级 | varchar(20) | 系统生成（只读） | 是 | 选项：提醒(黄色)、警告(橙色)、严重(红色) |
| alert_type | 预警类型 | varchar(50) | 系统生成（只读） | 是 | 如：盲板超期安装、检验超期、状态异常等 |
| alert_content | 预警内容 | text | 系统生成（只读） | 是 | 预警描述文本 |
| trigger_time | 触发时间 | datetime | 系统生成（只读） | 是 | - |
| related_object | 关联对象 | varchar(100) | 系统生成（只读） | 否 | 关联的盲板ID/作业票ID/隔离点ID |
| confirm_status | 确认状态 | varchar(20) | 系统生成（只读） | 是 | 选项：未确认、已确认 |
| confirm_person | 确认人 | varchar(50) | 用户录入 | 否 | - |
| confirm_time | 确认时间 | datetime | 系统生成 | 否 | - |
| process_status | 处理状态 | varchar(20) | 系统生成（只读） | 是 | 选项：待处理、处理中、已关闭 |

### 交互流程

#### 预警规则配置
1. 管理员进入"系统管理/规则引擎"菜单
2. 选择"预警规则"标签页
3. 可配置的预警规则包括：
   - 盲板超期安装预警：安装时间超过方案设计周期 N 天
   - 检验超期预警：距离下次检验日期不足 N 天
   - 状态异常预警：状态发生不符合流程的变更
   - 盲板超期使用预警：累计使用时长超过 N 天
4. 每条规则可配置：是否启用、预警等级、推送渠道、责任人

#### 预警触发与推送
1. 系统定时任务按预警规则扫描数据
2. 满足触发条件时，生成预警记录
3. 根据预警等级和配置的推送渠道发送通知：
   - 提醒（黄色）：系统内消息 + 移动端推送
   - 警告（橙色）：系统内消息 + 移动端推送 + 短信
   - 严重（红色）：系统内消息 + 移动端推送 + 短信 + 企业微信
4. 在总览看板预警信息栏实时显示

#### 预警确认与处理
1. 责任人收到预警通知
2. 进入预警详情页查看预警内容
3. 点击"确认"按钮，确认已收到预警
4. 填写处理意见和处置措施
5. 处理完成后，将预警状态更新为"已关闭"
6. 预警处理全程记录，形成闭环

#### 多渠道推送配置
- 系统内消息：默认启用，所有预警均推送
- 移动端推送：需配置推送服务（如Firebase/APNs）
- 短信：需配置短信网关
- 企业微信：需配置企业微信机器人Webhook
