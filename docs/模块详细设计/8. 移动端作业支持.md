# 移动端作业支持

## 功能概述

移动端是现场作业人员的核心操作界面，以扫码为主、手动输入为辅，注重简洁性和引导性。

### 菜单全路径

移动端APP（首页）

### 界面描述

#### 移动端首页
- **顶部区域**：用户头像、姓名、角色、当前待办任务数
- **功能快捷入口**：扫码（大按钮，居中突出）、我的任务、待办审批、消息通知
- **任务列表区**：当前待执行的作业任务卡片列表
  - 每张卡片：作业票ID、风险等级标签（颜色标识）、作业内容摘要、当前步骤、状态
  - 点击卡片进入作业执行流程

#### 扫码界面
- 全屏扫码取景框
- 支持二维码和条形码识别
- 扫码成功后自动识别编码类型（盲板码/位置码/作业票码/人员码）
- 识别结果展示及后续操作引导

#### 作业执行引导页
- 步骤指示器（顶部，显示当前进度如 3/8）
- 操作指引区（当前步骤的文字说明和图示）
- 操作确认区（扫码/表单/签名/拍照等）
- 底部按钮（上一步/下一步）

#### 消息通知页
- 通知列表（按时间倒序）
- 通知类型图标：审批通知、预警通知、停工通知、任务通知
- 未读通知红色角标
- 点击通知跳转到对应处理页面

### 交互流程

#### 扫码操作
1. 用户在首页点击"扫码"按钮或从任务中触发扫码
2. 系统打开全屏扫码界面
3. 用户对准二维码/条形码扫描
4. 系统自动识别编码类型：
   - 盲板码 → 跳转到盲板领用/安装确认页面
   - 位置码 → 跳转到位置到达确认页面
   - 作业票码 → 跳转到作业票详情页面
   - 人员码 → 跳转到人员身份确认页面
5. 扫码结果自动执行对应的校验逻辑

#### 作业任务接收与执行
1. 作业人员收到作业任务推送通知
2. 打开移动端，首页"我的任务"显示待办任务
3. 点击任务卡片进入作业执行引导页
4. 系统按步骤引导操作（详见7.4.2现场执行流程）
5. 每完成一步，系统自动进入下一步
6. 遇到Hold Point时自动暂停，等待确认
7. 所有步骤完成后，确认完工

#### Hold Point确认（移动端）
1. 到达Hold Point节点时，系统自动弹出确认界面
2. 显示当前Hold Point的名称和确认内容
3. 确认人逐项检查确认
4. 在电子签名板上手写签名
5. 点击"确认完成"提交
6. 确认通过后自动进入下一步

#### 拍照上传
1. 在关键操作步骤（位置确认、安装确认、效果确认等）
2. 用户点击"拍照"按钮
3. 系统调用设备相机
4. 拍照后自动关联到当前操作记录
5. 支持多张照片连续拍摄
6. 照片自动压缩上传

#### 离线模式
1. 当网络信号不佳或无网络时，系统自动检测到离线状态
2. 界面左上角显示"离线模式"标识
3. 关键作业数据自动缓存到本地：
   - 当前作业任务数据
   - 已扫码的盲板和位置信息
   - 操作确认记录
4. 离线期间的操作记录暂存在本地
5. 网络恢复后自动同步到服务器
6. 同步完成后显示同步结果
7. 如同步过程中发现数据冲突，提示用户处理

#### 消息推送
1. 系统后台触发通知事件时，向移动端推送消息
2. 推送类型及对应操作：
   - 审批通知 → 点击跳转到审批页面
   - 预警通知 → 点击跳转到预警详情
   - 停工通知 → 点击跳转到停工通知页面（锁定操作界面）
   - 任务通知 → 点击跳转到任务详情
3. 未读通知在APP图标和首页显示红色角标

#### 一键停工响应
1. 停工指令下发后，移动端立即收到推送
2. 手机振动+声音告警
3. 自动弹出停工通知页面（即使APP在后台）
4. 操作界面被锁定，仅显示停工通知
5. 锁定界面包含：停工范围、原因、时间、联系人
6. 复工后自动解锁操作界面
