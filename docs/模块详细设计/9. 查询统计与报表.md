# 查询统计与报表

## 功能概述

提供多维度数据查询、统计分析、报表生成和KPI看板功能，支持Excel、PDF、CSV格式导出。

### 菜单全路径

查询统计与报表 / [具体报表类型]

### 界面描述

#### 报表选择与配置页
- **报表类型导航**：左侧菜单列出所有报表类型
  - 盲板台账报表
  - 作业统计报表
  - 作业完成率分析
  - 异常事件分析
  - KPI看板
  - 合规审计报表
- **报表配置区**：根据选择的报表类型显示对应的筛选条件和参数配置
- **报表预览区**：主区域展示报表数据（表格/图表形式）
- **导出按钮区**：Excel导出、PDF导出、CSV导出按钮

---

### 盲板台账报表

#### 菜单全路径

查询统计与报表 / 盲板台账报表

#### 界面描述
- **筛选条件**：装置/单元（树形选择）、盲板型号下拉选择、DN范围输入、PN范围输入、材质下拉选择、当前状态下拉选择、生命周期状态下拉选择
- **报表展示**：数据表格，列同盲板主数据列表
- **导出**：支持Excel/CSV导出当前筛选结果

#### 字段描述
同盲板主数据字段（7.1.1节）

#### 交互流程
1. 用户选择"盲板台账报表"
2. 配置筛选条件
3. 点击"查询"按钮生成报表
4. 报表数据以表格形式展示
5. 点击"导出Excel"导出当前查询结果
6. 支持按装置/区域汇总统计（汇总行显示各装置盲板数量）

### 作业统计报表

#### 菜单全路径

查询统计与报表 / 作业统计报表

#### 界面描述
- **筛选条件**：时间范围（开始日期/结束日期）、装置/单元选择、风险等级多选、作业类型选择、作业状态下拉选择
- **统计维度切换**：按时间统计（日/周/月/年）、按装置统计、按风险等级统计
- **报表展示**：
  - 统计图表区：柱状图/折线图展示作业数量趋势
  - 数据表格区：详细统计数据
- **统计指标**：作业总数、完成数、完成率、异常数、异常率、平均作业时长

#### 字段描述

| 指标名 | 中文名 | 数据类型 | 计算方式 |
|--------|--------|---------|---------|
| total_count | 作业总数 | int | 统计周期内作业票总数 |
| completed_count | 完成数 | int | work_status='已完成'的作业票数 |
| completion_rate | 完成率 | decimal(5,2) | 完成数/作业总数×100% |
| abnormal_count | 异常数 | int | 关联异常事件的作业票数 |
| abnormal_rate | 异常率 | decimal(5,2) | 异常数/作业总数×100% |
| avg_duration | 平均作业时长 | decimal(8,1) | 所有已完成作业的平均耗时（小时） |
| on_time_count | 按时完成数 | int | 在计划时间内完成的作业数 |
| on_time_rate | 按时完成率 | decimal(5,2) | 按时完成数/完成数×100% |

#### 交互流程
1. 用户选择"作业统计报表"
2. 设置时间范围和筛选条件
3. 选择统计维度（按时间/按装置/按风险等级）
4. 点击"查询"生成报表
5. 图表和表格联动展示
6. 鼠标悬停在图表数据点上显示具体数值
7. 点击图表数据点可下钻查看明细数据
8. 支持导出图表和表格数据

### 作业完成率分析

#### 菜单全路径

查询统计与报表 / 作业完成率分析

#### 界面描述
- **筛选条件**：时间范围、装置/区域选择
- **分析展示**：
  - **完成率趋势图**：折线图展示各时间段的完成率变化趋势
  - **装置完成率对比图**：横向柱状图对比各装置的完成率
  - **按时完成率仪表盘**：仪表盘展示整体按时完成率
  - **未完成原因分析**：饼图展示未完成作业的原因分布
- **数据表格**：各装置的完成率详细数据

#### 交互流程
1. 用户选择"作业完成率分析"
2. 设置时间范围和装置范围
3. 系统生成多维度分析图表
4. 完成率低于目标值（90%）的装置用红色标识
5. 点击装置柱状条可查看该装置的详细作业列表

---

### 异常事件分析

#### 菜单全路径

查询统计与报表 / 异常事件分析

#### 界面描述
- **筛选条件**：时间范围、异常类型多选、异常等级多选、装置/区域选择
- **分析展示**：
  - **异常分类统计**：柱状图展示各类异常事件数量
  - **异常趋势分析**：折线图展示异常事件的时间趋势
  - **异常等级分布**：饼图展示提醒/警告/严重的比例
  - **装置异常排名**：横向柱状图展示异常最多的Top10装置
- **数据表格**：异常事件明细列表

#### 交互流程
1. 用户选择"异常事件分析"
2. 设置筛选条件
3. 系统生成异常分析图表
4. 点击图表分类可下钻查看该类异常的详细记录
5. 支持导出分析报告

### KPI看板

#### 菜单全路径

查询统计与报表 / KPI看板

#### 界面描述
- **KPI卡片网格布局**：每个KPI指标独立卡片展示
  - 指标名称
  - 当前值（大字号）
  - 目标值（小字号）
  - 达标状态图标（达标=绿色对勾、未达标=红色感叹号）
  - 与上期对比趋势箭头（上升/下降/持平）
- **KPI指标列表**：

| 编号 | KPI名称 | 计算方式 | 目标值 |
|------|---------|---------|--------|
| KPI1 | 盲板数字化台账覆盖率 | 已入库盲板数/全厂盲板总数 | ≥98% |
| KPI2 | 隔离点主数据准确率 | 随机抽查准确率 | ≥95% |
| KPI3 | 作业流程标准化执行率 | 按标准流程完成的作业/总作业数 | 100% |
| KPI4 | 五码一致校验通过率 | 校验通过次数/总扫码校验次数 | ≥99% |
| KPI5 | Hold Point执行率 | 已确认HP数/应确认HP总数 | 100% |
| KPI6 | 盲板状态实时更新率 | 30分钟内更新的记录数/总变更记录数 | ≥98% |
| KPI7 | 异常预警响应时间 | 预警触发到确认响应的时间 | ≤15分钟 |
| KPI8 | 作业票按期完工作业率 | 有效期内完成的作业票/总作业票数 | ≥90% |
| KPI9 | 系统月可用率 | 月度系统正常运行时间/月度总时间 | ≥99.5% |

#### 交互流程
1. 用户选择"KPI看板"
2. 系统自动计算并展示所有KPI指标的当前值
3. 达标状态实时更新
4. 点击某个KPI卡片可查看该指标的详细趋势图
5. KPI数据每日自动更新，支持手动刷新

### 合规审计报表

#### 菜单全路径

查询统计与报表 / 合规审计报表

#### 界面描述
- **报表类型选择**：审计报表类型下拉选择
  - 盲板台账审计报表
  - 作业票审计报表
  - 审批记录审计报表
  - 操作日志审计报表
  - 异常事件审计报表
- **筛选条件**：审计时间范围、装置/区域选择
- **报表预览**：按照审计规范格式展示报表内容
- **导出**：PDF导出（带审计章模板）

#### 交互流程
1. 用户选择"合规审计报表"
2. 选择报表类型
3. 设置审计时间范围
4. 点击"生成报表"按钮
5. 系统按审计规范格式生成报表
6. 预览报表内容
7. 点击"导出PDF"导出审计报表（含封面、目录、页码、审计章模板）
8. 导出文件可直接用于合规审计提交
